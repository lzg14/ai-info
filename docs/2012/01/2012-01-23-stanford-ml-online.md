# Stanford在线机器学习课程火爆

📅 2012-01-23

<!-- 正文开始 -->
2012年1月，Andrew Ng在Coursera上发布的Stanford机器学习课程成为最受欢迎的在线课程之一。这门课程最终吸引了超过400万学生。

课程的火爆得益于MOOC（大型开放在线课程）模式的兴起。任何人只要有网络连接，就可以学习世界顶级大学的课程。ML education democratization加速了AI人才的培养。

Andrew Ng后来创立了Coursera和deeplearning.ai，继续推动AI教育的普及。这波在线教育浪潮为深度学习社区培养了大批新血。
