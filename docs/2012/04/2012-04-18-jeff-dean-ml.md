# Jeff Dean构建Google机器学习基础设施

2012年，Jeff Dean在Google内部推动了机器学习基础设施的大规模建设。作为Google Brain项目的核心人物之一，他领导开发了用于训练深度神经网络的分布式计算系统。

Jeff Dean和Rajat Monga等人合作，探索了深度学习在Google产品中的应用潜力。DistBelief系统的设计允许研究者快速实验各种网络架构和超参数设置。

Jeff Dean的工作为Google后续的AI产品化奠定了坚实基础，包括搜索排名优化、语音识别和图像识别等功能都受益于这些基础设施。
