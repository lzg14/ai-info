# 深度学习在语音识别中的突破：微软突破50年瓶颈

2012年，微软研究院的俞栋、邓力团队首次将深度神经网络（DNN）应用于大词汇量连续语音识别，在Switchboard基准上将错误率降低了约20%——这是该领域10年来的最大进步。

## 背景

语音识别在深度学习出现之前，依赖GMM-HMM框架，进步缓慢。2012年的突破证明了深度学习能够捕捉语音信号中的复杂模式。

## 技术方法

微软的方法使用深度置信网络（DBN）进行声学建模：将语音的频谱特征输入DNN，预测每个帧对应的音素。DNN能够更好地建模语音的动态特性和非线性关系。

## 后续

这一突破引发了语音识别领域的深度学习热潮：Google于2012年将DNN应用于Google Voice搜索，百度、科大讯飞等公司跟进，深度学习成为语音识别的主流方法。
