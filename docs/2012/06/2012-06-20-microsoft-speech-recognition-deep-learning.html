微软研究院语音识别深度学习取得重大突破

入库 2012-06-20

2012年6月，微软研究院宣布其语音识别团队使用深度神经网络将语音识别错误率降低了30%以上。这一突破意味着Cortana语音助手等产品的核心技术取得重大进展。微软的深度学习方法取代了传统的GMM-HMM模型，成为语音识别领域的新标准。

微软研究院的这一成果与Google Brain项目几乎同时推进，标志着工业界全面进入深度学习时代。此后，苹果Siri、Google Now等语音助手纷纷采用深度学习技术。
