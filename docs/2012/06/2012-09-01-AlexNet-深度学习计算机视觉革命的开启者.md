# AlexNet：深度学习计算机视觉革命的开启者

📅 2012-09-01

<!-- 正文开始 -->
2012年9月，Geoffrey Hinton的学生Alex Krizhevsky和Ilya Sutskever在ImageNet大规模视觉识别挑战赛（ILSVRC）上发表了AlexNet，以16.4%的top-5错误率大幅超越传统方法的26.2%，开启了深度学习在计算机视觉领域的统治时代。

## 技术架构

AlexNet包含8层卷积神经网络（5层卷积+3层全连接），使用ReLU激活函数、GPU并行训练、Dropout正则化和数据增强技术。其核心创新是用GPU（NVIDIA GTX 580）训练大规模卷积神经网络，训练速度远超CPU。

## 历史意义

AlexNet是深度学习革命的导火索：它证明了深层卷积网络能够在大规模视觉任务上取得压倒性优势，让"深度"成为视觉识别的新范式。Hinton因此获得了深度学习教父的地位，后来的学生也成为AI领域的重要力量。

## 影响

AlexNet的成功直接催生了深度学习在工业界的应用热潮——Google、Facebook、Microsoft等科技巨头纷纷建立深度学习团队，推动了深度学习在语音识别、NLP等领域的全面扩展。
