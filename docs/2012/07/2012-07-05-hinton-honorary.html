Geoffrey Hinton获爱丁堡大学荣誉学位

入库 2012-07-05

2012年7月，"深度学习之父"Geoffrey Hinton获得爱丁堡大学授予的荣誉博士学位。这是对他在人工智能和神经网络领域开创性贡献的认可。

Hinton在剑桥大学获得实验心理学学士学位后，在爱丁堡大学获得人工智能博士学位。他的研究跨越了四十多年，见证了神经网络从被冷遇到成为主流的整个历程。

这一荣誉也标志着学术界对连接主义和神经网络的重新审视，为后续深度学习的爆发营造了有利的学术氛围。
