# Bengio深度学习理论研究

📅 2012-08-14

<!-- 正文开始 -->
2012年，Yoshua Bengio发表了关于深度学习理论的重要综述文章，系统性地梳理了深度网络为何有效。他提出了"贪婪逐层预训练"方法，通过无监督学习逐层初始化网络参数。

Bengio的理论工作强调，理解深度学习需要从表示学习、稀疏编码和层次化特征提取的角度出发。他的实验室成为培养深度学习研究者的重要基地。

Bengio与LeCun、Hinton一起被业界尊称为"深度学习三巨头"，他们共同奠定了现代深度学习的基础。
