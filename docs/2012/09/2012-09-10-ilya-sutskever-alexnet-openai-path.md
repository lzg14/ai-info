# Ilya Sutskever从AlexNet到OpenAI的深度学习之路

📅 2012-09-10

<!-- 正文开始 -->
2012年9月，Ilya Sutskever作为AlexNet论文的第一作者开始受到学术界关注。这位来自多伦多大学的年轻研究者师从Geoffrey Hinton，在ImageNet竞赛中展示了深度卷积神经网络的强大能力。

Sutskever后来成为OpenAI的联合创始人和首席科学家，参与了[GPT](../../glossary/terms/gpt.md)系列模型的开发。他的研究涵盖了从神经网络基础理论到大规模语言模型的各个方向，是深度学习时代最具影响力的研究者之一。
