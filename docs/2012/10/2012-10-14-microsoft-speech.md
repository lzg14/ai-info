# 微软语音识别引入深度学习

📅 2012-10-14

<!-- 正文开始 -->
2012年，微软研究院的语音识别团队率先将深度学习应用于语音识别系统。他们用深度神经网络替代高斯混合模型，显著提升了识别准确率。

微软的突破性工作由俞栋、Larry Heck等研究者完成。深度神经网络（DNN）能够更好地建模语音信号的复杂分布，捕获长时序相关性。

这一进展为后来Cortana、Siri等语音助手的商业化应用奠定了技术基础。微软在语音识别领域的技术领先地位一直保持至今。
