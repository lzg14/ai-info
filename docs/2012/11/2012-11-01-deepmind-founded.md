# DeepMind Technologies成立

2010年，Demis Hassabis、 Shane Legg和 Mustafa Suleyman在伦敦创立了DeepMind Technologies。2012年公司已初具规模，开始引起Google等巨头的关注。

DeepMind的目标是开发通用人工智能（AGI），将神经科学与深度学习结合。公司早期聚焦于强化学习，开发能够自己学习玩游戏的AI系统。

DeepMind的创始团队背景多元：Hassabis是棋类神童和游戏设计师，Legg是机器学习研究员，Suleyman是人权律师。这种跨学科组合在AI公司中较为罕见。

2014年，Google以约5亿美元收购DeepMind，开启了AI发展史的新篇章。
