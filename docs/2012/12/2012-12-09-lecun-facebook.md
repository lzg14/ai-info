# Yann LeCun加入Facebook

2013年初，Facebook宣布聘请深度学习先驱Yann LeCun和Yoshua Bengio担任顾问，标志着社交网络巨头正式进军AI研究。LeCun后来成为Facebook AI Research（FAIR）的负责人。

LeCun的加入为Facebook带来了世界级的AI研究能力。他帮助建立了开放的研究文化，FAIR发表的论文大多公开发布，推动了整个领域的进步。

FAIR的成立标志着科技巨头AI军备竞赛的开始。Google（Brain）、Facebook（FAIR）、Microsoft和Amazon纷纷建立AI研究机构。
