# NVIDIA GTC大会：GPU成为深度学习核心

2013年3月，NVIDIA在圣何塞举办了GPU技术大会（GTC），会上展示了CUDA架构在深度学习训练中的革命性优势。GPU的并行计算能力使得神经网络的训练速度比CPU提升了数十倍。

NVIDIA在大会上宣布了针对深度学习优化的CUDA工具链和cuDNN库，这些工具极大地简化了深度学习框架的开发。GPU计算 democratization 使得更多研究者和工程师能够训练大规模神经网络。

GTC 2013成为深度学习硬件基础设施发展的重要转折点此后每年GTC都成为展示AI计算能力的顶级舞台。
