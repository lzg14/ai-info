# GPU并行计算加速深度学习训练

2013年，研究者开始系统性地探索GPU在深度学习训练中的加速作用。COTS HPC系统使用多个GPU进行神经网络训练，显著缩短了训练时间。

GPU的并行计算架构完美契合神经网络中矩阵运算的特点，一个GPU可以并行处理数千个神经元。一台8-GPU服务器的计算能力可以媲美传统的CPU集群。

这一年发表的多个工作详细分析了GPU训练深度网络的具体技巧，包括批量大小选择、学习率调整和梯度同步策略，为后来的分布式训练研究奠定了基础。
