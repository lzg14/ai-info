# Geoffrey Hinton发布Coursera神经网络课程

2013年5月，"深度学习之父"Geoffrey Hinton在Coursera上发布了著名的"Neural Networks for Machine Learning"课程。这门课程将深度学习的核心理论和实践知识系统地传授给全球学习者，被认为是ML教育史上最重要的事件之一。

课程内容涵盖感知器、BP算法、CNN、RBM、深度信念网络等核心主题。Hinton在课程中深入浅出地讲解了为什么深层网络比浅层网络更强大，以及如何有效地训练深度神经网络。

这门课程的开设标志着深度学习知识开始大规模普及。许多后来的深度学习研究者都表示，这门课程是他们入行的起点。Coursera的在线教育模式让全球数万人同时学习最前沿的AI技术。
