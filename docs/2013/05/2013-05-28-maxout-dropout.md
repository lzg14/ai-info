# Maxout网络和Dropout正则化研究

2013年，Ian Goodfellow等研究者提出了Maxout网络，这是一种新型的激活函数设计。同时，Hinton团队的Dropout技术在这一年得到了更广泛的验证和应用。

Dropout通过在训练时随机丢弃神经元来防止过拟合，效果显著。Maxout则通过分段线性函数学习最优的激活形状，提高了网络的表达能力。

Goodfellow还在这一年发表了关于深度网络泛化能力的理论研究，探讨了为什么看似过参数化的网络仍然具有良好的泛化性能。
