# Google深度学习项目取得突破进展

2013年，Google的人工智能研究团队在Jeff Dean的领导下取得了多项重要突破。Google Brain项目展示了训练大规模深度神经网络的能力，可以从YouTube视频中学习识别猫等物体。

Google的DistBelief系统证明了深度学习可以在数千台服务器上并行训练。团队还发表了关于"深度ICA"等高级表示学习技术的论文，展示了无监督学习的潜力。

这一年也是Google收购DeepMind的前奏，公司开始加大对深度学习和通用人工智能的投资力度。Google的战略眼光为后来AlphaGo等项目埋下了伏笔。
