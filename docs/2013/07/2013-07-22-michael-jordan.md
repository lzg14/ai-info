# Michael Jordan推动深度学习理论发展

📅 2013-07-22

<!-- 正文开始 -->
2013年，UC Berkeley的Michael I. Jordan教授在深度学习的理论基础方面做出了重要贡献。他的团队致力于理解深度网络的表达能力，为"深度"这一概念提供理论支撑。

Jordan的研究探讨了为什么堆叠多层非线性函数能够学习到有用的表示，为深度学习的有效性提供了统计学解释。他的工作强调了层次化表示在复杂数据建模中的重要性。

作为机器学习领域的泰斗，Jordan的参与为深度学习研究带来了更多的理论严谨性，也为这一领域吸引了更多统计学家的关注。
