# 深度学习综述论文发表

2013年9月，Yoshua Bengio、Yann LeCun和Geoffrey Hinton三位深度学习先驱在Science杂志上发表了深度学习的综述文章，系统性地总结了领域进展并展望未来。

文章强调了逐层贪婪预训练、无监督学习和深度表示学习的重要性，回顾了CNN、RNN和自编码器等主要架构。文章指出，深度学习之所以成功，是因为能够从原始数据中学习到层次化的表示。

这篇综述为学术界提供了权威的学习材料，也帮助政策制定者和公众理解深度学习的潜力和局限性。
