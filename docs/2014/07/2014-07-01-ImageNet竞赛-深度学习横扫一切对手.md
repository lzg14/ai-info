# ImageNet竞赛：深度学习横扫一切对手

2014年的ImageNet大规模视觉识别挑战赛（ILSVRC）上，深度学习方法彻底统治了竞赛榜单——前几名全部是深度学习方案，传统方法首次被边缘化。

## 成绩回顾

- 2010年：传统方法 top-5 错误率 28%
- 2011年：传统方法改进 top-5 错误率 26%
- 2012年：AlexNet（深度学习）top-5 错误率 16.4%
- 2013年：深度学习 继续领先，错误率降至约 11%
- **2014年**：GoogLeNet（VGGNet等）错误率降至约 7%，首次超越人类平均水平的 5%

## GoogLeNet与VGGNet

2014年ILSVRC的两大明星：GoogLeNet（Google团队）提出Inception模块，在22层深度下仍保持计算效率；VGGNet（牛津大学VGG团队）用更小的3×3卷积核堆叠出更深的网络，证明了"深度"的重要性。

## 标志性意义

ImageNet挑战赛的统治性胜利标志着计算机视觉领域深度学习革命的最终完成——从2012年AlexNet证明深度学习可行，到2014年深度学习全面替代传统方法，只用了三年。
