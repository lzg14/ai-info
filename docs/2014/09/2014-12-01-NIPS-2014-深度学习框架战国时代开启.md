# NIPS 2014：深度学习框架战国时代开启

2014年NIPS见证了深度学习框架生态的快速成型：Caffe、Torch7、Theano、CGT等框架成为研究主流，深度学习工具开始从"自己写的实验代码"向"标准化框架"转变。

## 主流框架

**Caffe**：由UC Berkeley的贾扬清等人开发，以速度快和易用性著称，尤其擅长计算机视觉任务。其模型动物园（Model Zoo）成为复现最新研究的重要资源。

**Torch7**：基于Lua语言的科学计算框架，在研究社区有大量用户。其核心优势是灵活的张量运算和GPU加速，后来Facebook AI用它开发了早期的PyTorch。

**Theano**：由蒙特利尔大学的Bengio团队开发的符号计算框架，是现代自动微分工具的先驱。尽管Theano后来停止了开发，但其设计思想影响了TensorFlow、PyTorch等所有后继框架。

## 意义

2014年后，深度学习研究不再需要从零写GPU代码，框架降低了研究门槛，加速了创新的传播和迭代。
