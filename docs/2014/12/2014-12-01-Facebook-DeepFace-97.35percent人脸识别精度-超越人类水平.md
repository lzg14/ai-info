# Facebook DeepFace：97.35%人脸识别精度，超越人类水平

2014年3月，Facebook AI Research发表DeepFace论文，宣布其人脸识别系统DeepFace在LFW（Labeled Faces in the Wild）基准上达到了97.35%的准确率——首次超越人类的95.53%平均水平。

## 技术架构

DeepFace使用了9层深度卷积神经网络，包含超过1.2亿个参数，训练于400万张人脸图像数据集。关键创新在于使用了3D对齐技术，将人脸图像对齐到统一的正面视角，显著降低了姿态变化对识别的影响。

## 重要意义

DeepFace的结果是一个标志性事件：AI在人脸识别这一人类擅长感知任务上超越了人类。这不仅证明了深度学习的强大能力，也引发了对隐私、AI伦理的广泛讨论。

## 后续竞争

DeepFace的成功刺激了整个行业对人脸识别的投入。Google的FaceNet（2015年）进一步将准确率提升到99.63%，人脸识别技术开始在安防、支付、社交等领域全面商业化。
