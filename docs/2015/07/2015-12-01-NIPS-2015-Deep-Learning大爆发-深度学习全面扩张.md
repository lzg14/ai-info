# NIPS 2015：Deep Learning大爆发，深度学习全面扩张

2015年NIPS参会人数超过6000人，比2014年翻了一倍，深度学习相关论文占比超过80%。这一年NIPS见证了深度学习从"一种方法"变成"几乎唯一方法"的历史性转变。

## 重要论文

NIPS 2015涌现了大量里程碑论文：
- **ResNet**（何恺明等）：深度残差网络
- **Neural Machine Translation**（Bahdanau Attention）：注意力机制NMT
- **Spatial [Transformer](../../../glossary/terms/transformer.md) Networks**：可学习的空间变换模块
- **Batch Renormalization**：BatchNorm的改进版本

## 工业界参与

Google、Facebook、Microsoft、Amazon等公司在NIPS大规模招募人才，深度学习PhD起薪突破50万美元。工业界和学术界的界限日益模糊，大量教授创办或加入AI公司。

## 算力竞争

NIPS 2015也成为GPU计算能力的展示场：NVIDIA、Intel、Google等公司展示深度学习加速硬件，算力成为AI研究的核心竞争力。
