# Microsoft Azure：4.5亿美元云基础设施布局中国AI

2015年，微软宣布将在中国投入超过4.5亿美元建设Azure云基础设施，并在中国推出Cognitive Services认知服务，将AI能力以API形式开放给开发者。

## Azure AI服务

微软Azure的认知服务包括：
- **计算机视觉API**：图像识别、人脸识别、OCR
- **语音识别API**：语音转文字、文本转语音
- **自然语言理解**：情感分析、关键短语提取
- **搜索API**：Bing搜索能力

## 意义

Azure Cognitive Services让任何开发者不需要深度学习背景就能使用AI能力。大量初创公司基于Azure Cognitive Services开发智能应用，推动了AI民主化。

## 中国市场

微软Azure通过与世纪互联合作在中国落地，成为首个在中国合法运营的国际公有云。这为中国开发者使用国际AI技术提供了渠道。
