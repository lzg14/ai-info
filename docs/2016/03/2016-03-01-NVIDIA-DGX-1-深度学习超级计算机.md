# NVIDIA DGX-1：深度学习超级计算机

2016年6月，NVIDIA推出DGX-1超级计算机，这是第一台专门为深度学习设计的超级计算机。DGX-1整合了8块Tesla P100 GPU，提供高达170 TFLOPS的深度学习算力。

## 硬件规格

- 8× NVIDIA Tesla P100 GPU
- 170 TFLOPS（深度学习训练）
- NVLink互联，带宽是PCIe的5倍
- 预装Caffe、TensorFlow等深度学习框架

## 意义

DGX-1将"国家超算中心级别"的算力带入企业实验室，将大型模型的训练时间从数周缩短到数小时。它是深度学习算力民主化的重要里程碑。

## 定价

DGX-1定价约12.9万美元，面向AI研究机构和企业。价格虽高，但相较于自建同等算力的集群已大幅降低。
