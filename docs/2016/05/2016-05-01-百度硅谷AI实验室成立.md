# 百度设立硅谷人工智能实验室：中美双核研发体系成型

2016年5月，百度宣布在硅谷成立人工智能研究院（SVAIL），由百度首席科学家吴恩达（Andrew Ng）主导建设。该实验室聚焦深度学习、自然语言处理和自动驾驶等前沿领域，与北京百度深度学习实验室形成中美双核研发体系。

吴恩达曾主导Google Brain项目并推动Google Brain在YouTube视频中识别猫的实验，其加入百度标志着中国科技公司开始吸引顶尖AI人才回流。百度还招募了包括林元庆、徐伟在内的多位世界级AI专家。

百度AI战略以百度大脑为核心，集成语音识别、图像识别、自然语言处理等多项技术。2017年百度推出Apollo自动驾驶平台，技术源头可追溯至此时期的硅谷研发布局。
