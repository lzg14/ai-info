# Google Unveils Tensor Processing Unit Custom AI Chip

📅 2016-07-18 | 📎 爱范儿 | ⭐ 精选

<!-- 正文开始 -->
Google announced the existence of its Tensor Processing Unit (TPU) in July 2016, revealing that the company had been using custom-designed chips to power its machine learning workloads since 2015. The TPU represented a significant departure from using general-purpose graphics processing units (GPUs) for AI computation, instead offering a purpose-built solution optimized specifically for neural network inference. Google CEO Sundar Pichai explained that the TPU delivered superior performance per watt for machine learning tasks, making it more energy-efficient for large-scale deployments. The chip was developed by Google's infrastructure team and was first deployed to power RankBrain, a machine learning system used to improve search result relevance, as well as AlphaGo's historic matches against Go champions. TPUs excelled at the matrix multiplication operations that form the backbone of neural network computations, performing them with dedicated hardware rather than general-purpose arithmetic logic. Google reported that the TPU offered an order of magnitude better performance per watt compared to contemporary GPUs and CPUs when running production machine learning workloads. The announcement validated the growing trend of hardware specialization for AI applications, with other major tech companies subsequently developing their own custom AI chips. Google later released details about the TPU's architecture in a academic paper, sharing more information about its systolic array design and precision choices.
