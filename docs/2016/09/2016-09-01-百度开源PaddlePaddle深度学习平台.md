# 百度开源深度学习平台PaddlePaddle：打造中国AI基础设施

2016年9月，百度正式开源其自主研发的深度学习平台PaddlePaddle（Parallel Distributed Deep Learning）。作为中国最早开源的深度学习框架，PaddlePaddle支持多种神经网络架构，并针对中文自然语言处理任务进行了深度优化。

百度自2013年起投入深度学习研发，PaddlePaddle经过内部多年迭代后选择开源，旨在降低中国企业和开发者使用深度学习技术的门槛。该平台支持GPU集群分布式训练，并提供丰富的预训练模型库。

PaddlePaddle的开源标志着中国科技巨头开始构建自主AI生态。后续百度又推出ERNIE系列模型，将PaddlePaddle打造为支撑百度AI战略的核心技术底座。
