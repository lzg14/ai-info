# AlphaGo Defeats World Champion Ke Jie 3-0 at Wuzhen Summit

📅 2017-05-27 | ⭐ 精选

<!-- 正文开始 -->
2017年5月，在中国乌镇围棋峰会上，由谷歌旗下DeepMind公司开发的人工智能程序AlphaGo与排名世界第一的世界围棋冠军柯洁进行了一场备受瞩目的人机大战。这场对决引起了全球科技界和围棋界的广泛关注，被视为人工智能发展史上的又一个重要时刻。

经过三番棋的激烈较量，AlphaGo最终以3比0的总比分完胜柯洁。5月27日，柯洁以中盘投子结束了与AlphaGo的最后一场比赛，最终比分定格在0比3。这一结果再次证明了人工智能在围棋这项被视为人类智慧最后堡垒的策略游戏中的绝对优势。柯洁在赛后表示，AlphaGo的棋艺已经达到了他无法企及的高度，他对人工智能的快速发展感到既敬畏又震惊。

在2017人机大战最后一局比赛结束后的发布会上，AlphaGo之父、DeepMind创始人戴密斯·哈萨比斯（Demis Hassabis）宣布了一个令人意外的决定：AlphaGo将从围棋赛场上退役。哈萨比斯表示，AlphaGo团队将把目光投向更加远大的目标，包括将人工智能技术应用于医疗、节能等关乎人类福祉的重要领域。AlphaGo的退役并不意味着这项技术的终结，而是预示着DeepMind将把在围棋领域积累的深度学习技术应用到更广泛的科学问题中。

这场人机大战不仅是围棋历史上的划时代事件，更是人工智能发展进程中的重要节点。它向全世界展示了深度学习和蒙特卡洛树搜索技术结合的巨大潜力，为后续人工智能技术在更多领域的应用开辟了道路。
