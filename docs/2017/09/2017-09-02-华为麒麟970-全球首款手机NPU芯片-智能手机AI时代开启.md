# 华为麒麟970：全球首款手机NPU芯片，智能手机AI时代开启

📅 2017-09-02

<!-- 正文开始 -->
2017年9月2日，华为在柏林IFA电子展上发布麒麟970芯片，这是全球首款内置NPU（神经网络处理单元）的移动端SoC，标志着智能手机AI计算进入专用加速时代。

## NPU的突破

麒麟970集成了寒武纪授权的NPU IP，专门用于处理AI推理任务。在图像识别测试中，NPU的处理速度比CPU快25倍，能效比提升50倍。NPU使得手机可以在本地完成复杂的AI任务，而无需上传云端。

## 开创端侧AI

麒麟970开创了手机端侧AI芯片的先河。苹果A11 Bionic（同年9月iPhone X发布）、高通骁龙845（同年12月）相继跟进，"AI芯片"成为智能手机的新标配。

端侧AI的意义在于隐私保护（数据无需离开设备）和实时响应（无网络延迟）。华为通过自研NPU，在芯片层面建立了差异化竞争力，为后续Mate 10系列等产品的AI摄影能力奠定了硬件基础。
