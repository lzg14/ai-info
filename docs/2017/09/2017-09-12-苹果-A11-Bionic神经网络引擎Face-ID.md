# 苹果A11 Bionic：神经网络引擎，iPhone X的AI心脏

2017年9月12日，苹果发布iPhone X，搭载A11 Bionic芯片，这是苹果首次在自家SoC中集成专用神经网络引擎（Neural Engine）。A11 Bionic为Face ID、Animoji、ARKit等AI功能提供硬件支持。

## 神经网络引擎

A11 Bionic的Neural Engine是一个专用的AI推理加速单元，每秒可进行6000亿次矩阵运算，专门处理人脸识别、AR应用中场景理解等AI任务。Face ID能够在黑暗环境、快速移动等条件下完成3D人脸识别，Neural Engine是关键支撑。

## 与安卓阵营的竞争

同月华为发布的麒麟970（搭载NPU）和苹果的A11 Bionic几乎同期发布，两者都将AI专用芯片作为手机SoC的新标配。高通随后在骁龙845（2017年12月）中大幅提升了AI计算能力。

三大手机芯片厂商的共同选择，标志着AI芯片从云端向端侧（手机端）的战略转移，也是智能手机从"通信工具"向"智能助手"转变的硬件基础。
