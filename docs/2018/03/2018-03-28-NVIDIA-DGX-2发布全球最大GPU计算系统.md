# NVIDIA DGX-2发布，全球最大GPU计算系统算力达2PFLOPS

📅 2018-03-28

<!-- 正文开始 -->
NVIDIA在2018年3月发布了DGX-2超级计算系统，这是全球首款采用16颗V100 GPU互联形成的庞大计算平台，总算力高达2 PFLOPS（每秒2千万亿次浮点运算）。DGX-2采用NVSwitch技术实现GPU之间的高速互联，峰值带宽达到2.4TB/s，能够在15分钟内完成[BERT](../../glossary/terms/bert.md)模型的完整训练——这一任务在传统GPU服务器上需要数天时间。DGX-2的发布标志着大模型训练进入工业级算力时代，为后续[GPT](../../glossary/terms/gpt.md)-2、BERT-Large等超大模型的诞生提供了硬件基础。该系统定价约39.9万美元，主要面向AI研究机构和企业级用户，其设计理念深刻影响了当代AI基础设施的演进方向。
