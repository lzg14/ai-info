# Google Duplex实现AI自然对话，自动化预约走进现实

2018年5月，Google在I/O开发者大会上展示了Google Duplex语音AI系统，其能够以高度自然的方式代替用户进行电话预约。Duplex实现了自发式对话的突破——AI可以进行"嗯"、"啊"等拟人化表达，处理复杂对话上下文，甚至在对话不流畅时优雅地请求重复。现场演示中，Google Assistant成功为用户预约了理发店和餐厅，惊艳全场。该系统基于RNN（循环神经网络）和Tacotron语音合成技术开发，能够理解对话意图并生成自然语音。Duplex的发布引发了关于AI伦理和就业影响的广泛讨论，Google随后承诺将强制AI身份标识 Disclosure（告知对方为AI）。Duplex代表了语音交互的重大进步，是AI助手从"听懂指令"进化到"代替行动"的关键里程碑。
