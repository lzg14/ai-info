GitHub被微软75亿美元收购，全球最大代码平台易主

入库 2018-06-04

2018年6月4日，微软正式宣布以75亿美元全现金收购全球最大代码托管平台GitHub。这一交易于同年10月完成，GitHub继续保持独立运营，并引入微软企业级安全合规能力。GitHub拥有超过2800万开发者用户，托管超过8500万个代码仓库，是全球开源生态的核心枢纽。此次收购在开发者社区引发广泛讨论，部分开发者因微软过往对开源的保守态度而担忧，但收购后GitHub迅速推出免费私有仓库、GitHub Actions CI/CD等重磅功能，用户数从2800万快速增长至2023年的1亿以上。该交易被视为微软云战略的关键布局，也标志着开源社区与商业巨头深度融合的新阶段，对AI开源模型的传播与分发产生了深远影响。
