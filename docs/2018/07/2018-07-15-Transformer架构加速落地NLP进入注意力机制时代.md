# 架构加速落地，NLP进入注意力机制时代

📅 2018-07-15

<!-- 正文开始 -->
2017年Google发布的《Attention Is All You Need》论文在2018年进入大规模应用阶段，Transformer架构迅速成为NLP领域的主导模型。不同于RNN的序列依次处理方式，Transformer通过自注意力（Self-Attention）机制实现并行计算，能够直接建模任意距离的词语关系，训练速度提升数个量级。2018年，基于Transformer的[BERT](../../glossary/terms/bert.md)、[GPT](../../glossary/terms/gpt.md)-1、Transformer-XL等模型相继问世，全面取代了LSTM和GRU等传统序列模型。Transformer的成功也溢出到计算机视觉领域，催生了ViT（Vision Transformer）等革命性模型。其"注意力"核心思想——让模型学会"关注"输入中最相关的部分——已成为深度学习的通用范式，深刻影响了几乎所有AI子领域的技术发展路径。
