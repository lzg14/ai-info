# NVIDIA RTX 2080发布，图灵架构开启实时光线追踪时代

2018年8月20日，NVIDIA发布基于全新图灵（Turing）架构的GeForce RTX系列显卡，其中RTX 2080成为当年最受关注的消费级GPU。图灵架构首次在GPU中引入专用RT Core（光线追踪核心），支持实时光线追踪技术，使游戏和渲染的画面真实性获得质的飞跃。RTX 2080搭载8GB GDDR6显存，拥有2944个CUDA核心，在深度学习训练任务中比上代Pascal架构快约50%。该系列显卡还引入了Tensor Core，支持DLSS（深度学习超采样）技术。RTX系列的发布不仅革新了游戏产业，也为AI研究者和工程师提供了性价比更高的训练硬件，其 Turing Tensor Core对混合精度计算的支持直接加速了深度学习模型的迭代速度。
