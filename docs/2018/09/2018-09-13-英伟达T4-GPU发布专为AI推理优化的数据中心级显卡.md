# 英伟达T4 GPU发布，专为AI推理优化的数据中心级显卡

2018年9月，NVIDIA发布专为AI推理场景优化的Tesla T4 GPU，该卡基于图灵架构的精简版本，拥有320个Tensor Core和16GB GDDR6显存。T4的FP16推理性能达到65 TFLOPS，INT8推理性能更高达130 TOPS，相比CPU服务器可实现40倍推理加速。T4设计功耗仅75W，可直接插入标准服务器插槽，大幅降低了数据中心AI推理的硬件门槛。Google Cloud、AWS、阿里云等主流云服务商迅速引入T4实例，为企业提供低成本的AI推理服务。T4的发布标志着AI计算从"训练为王"向"推理优先"的战略转型，NVIDIA也因此进一步巩固了其在数据中心AI市场的垄断地位。
