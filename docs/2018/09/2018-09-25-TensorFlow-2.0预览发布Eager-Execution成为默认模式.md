# TensorFlow 2.0预览发布，Eager Execution成为默认模式

2018年9月25日，Google发布TensorFlow 2.0的首个预览版本，对框架进行了史上最重大改版。2.0版本将Eager Execution（动态图执行）设为默认模式，开发者无需先定义静态计算图即可直接执行操作，显著提升了调试效率和开发体验。同时，Keras被确立为中央高级API，tf.keras成为构建神经网络的推荐接口，简化了从模型定义到训练的全流程。TensorFlow 2.0还移除了过时API，统一了tf.contrib到标准API的迁移路径，并大幅减少了冗余函数。Google表示2.0版本的设计目标是"简单易用、跨平台兼容、生产级部署"，其中tf.function用于将动态图编译为高性能静态图，tf.saved_model支持模型标准化导出。这一版本被视为TensorFlow从研究到生产的关键转折点。
