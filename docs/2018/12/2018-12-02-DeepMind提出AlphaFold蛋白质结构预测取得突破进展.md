# DeepMind提出AlphaFold，蛋白质结构预测取得突破进展

📅 2018-12-02

<!-- 正文开始 -->
2018年12月，DeepMind在CASP13（蛋白质结构预测关键评估）竞赛中正式推出AlphaFold，引发科学界轰动。AlphaFold通过创新性地将深度学习与生物物理知识相结合，大幅提升了蛋白质三维结构预测的准确性。不同于传统方法依赖同源序列比对，AlphaFold引入了"[注意力机制](../../glossary/terms/attention-mechanism.md)"来学习蛋白质中氨基酸残基之间的距离关系，预测精度远超当时其他方法。虽然AlphaFold的完整版本在2019-2020年才正式公布，但其在CASP13的表现已预示着AI驱动的生物科学革命即将到来。蛋白质结构预测的突破为药物研发、疾病理解等领域开辟了新路径，是AI for Science的里程碑式成就。
