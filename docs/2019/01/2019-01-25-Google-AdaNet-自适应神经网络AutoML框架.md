# Google AdaNet：自适应神经网络 AutoML 框架

Google于2019年1月发布了AdaNet，这是一个快速灵活的自适应神经网络AutoML框架。AdaNet基于TensorFlow实现，能够自动搜索最优神经网络结构并集成多个子网络以提升模型性能。该框架整合了TensorFlow Hub modules、TensorFlow Model Analysis和Google Cloud's Hyperparameter Tuner等工具，大大简化了机器学习编程。AdaNet的目标是帮助开发者以最小的计算成本构建高质量的集成模型，推动了自动化机器学习技术的发展。
