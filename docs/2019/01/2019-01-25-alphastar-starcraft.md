# AlphaStar Defeats Professional StarCraft II Players

2019年1月25日，DeepMind与暴雪在网上直播，公布了在《星际争霸2》游戏中取得的进展，名为"AlphaStar"的人工智能在与两位人类职业选手TLO和MANA的比赛中，均以5比0取胜。这一事件标志着人工智能在高复杂度实时战略游戏领域取得了重大突破。

《星际争霸2》是有史以来最复杂的实时战略游戏之一，被广泛认为是AI研究的终极挑战之一。与围棋不同，星际争霸具有以下特点：非完全信息博弈（玩家无法看到全部战场）、巨大的动作空间、需要长期规划和战略决策、多兵种协同配合、以及对对手行为的实时推断。

AlphaStar是一个把游戏看作长序列建模学习任务的强化学习智能体，它的模型设计以长序列建模能力为核心。DeepMind团队使用了一种被称为"联盟训练"的方法，训练多个不同风格的AlphaStar智能体相互对战，让它们在学习过程中不断进化和提升。

在第一个版本之后，DeepMind继续进化AlphaStar。后来发布的版本能够以大师级别进行完整的《星际争霸2》比赛，在官方的人类玩家排名中排名前99.8%以上。这一成就展示了强化学习在处理复杂多智能体环境中的巨大潜力。

AlphaStar的技术突破不仅局限于游戏本身，其背后的强化学习技术、神经网络架构和训练方法对于解决现实世界中的复杂问题也具有重要参考价值，例如机器人控制、自动驾驶和资源调度等领域。

这次直播吸引了广泛关注，尽管最后一场人类选手扳回一局，但AlphaStar的表现已经证明了AI在需要战略思维和实时决策的复杂环境中可以达到超越人类的水平。这一成果发表在2019年10月的《Nature》杂志上。
