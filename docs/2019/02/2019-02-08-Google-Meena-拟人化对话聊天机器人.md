# Google Meena：追求拟人化对话的开域聊天机器人

Google于2020年1月发布了Meena，这是一种端到端神经对话模型，追求类人化的开放域对话能力。Meena采用Evolved Transformer（ET）架构，Encoder使用1个ET层（相当于2层Transformer），Decoder使用13个ET层（相当于26层Transformer），展现出极强的语言建模能力。该模型在 SSA（Senseivity Average）指标上达到了人类水平的79%，显著超越了现有的开放域聊天机器人。Meena的研究推动了对话AI向更自然、更智能的方向发展。
