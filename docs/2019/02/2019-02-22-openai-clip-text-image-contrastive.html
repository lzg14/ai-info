OpenAI CLIP：文本与图像对比学习新范式

入库 2019-02-22

基本信息

  • 日期：2019-02-22
  • 来源：OpenAI
  • URL：https://openai.com/blog/clip
  • 主题：多模态学习，对比学习，计算机视觉

内容摘要

2019年2月，OpenAI发布了CLIP（Contrastive Language-Image Pre-training），一个基于自然语言监督的多模态预训练模型。CLIP通过对比学习同时训练图像和文本编码器，在4亿个图文配对数据上进行预训练，实现了"zero-shot"分类能力——无需针对特定任务训练即可识别任意类别。CLIP打破了传统计算机视觉模型需要大量标注数据的限制，验证了大规模预训练+自然语言监督的有效性。这一方法后来成为多模态学习的重要基石，推动了多模态大模型的发展。
