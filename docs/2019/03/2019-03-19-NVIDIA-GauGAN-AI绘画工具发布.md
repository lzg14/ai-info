# NVIDIA GauGAN：涂鸦秒变逼真风景图的AI绘画工具

NVIDIA在2019年3月的GTC大会上展示了GauGAN，这是一款利用生成对抗网络（GAN）将涂鸦实时转换为逼真风景画的AI工具。用户只需使用画笔绘制简单的线条和形状，软件就能生成与之对应的逼真自然景观，包括云朵、树木、水面等元素。GauGAN使用在数百万张真实景观图像上训练的深度学习模型，理解场景中各元素的关系。GauGAN在SIGGRAPH 2019上荣获最佳实时现场演示奖和观众选择奖，展示了AI在创意领域的巨大潜力。
