Microsoft Build 2019 Azure AI Services Transform Enterprise Development

Microsoft官方博客2019-05-08入库 2019-05-08

Microsoft Build 2019 brought substantial AI announcements in May 2019, with Azure Cognitive Services receiving major updates and new AI-powered development tools. The standout announcement was the general availability of Azure Cognitive Services Containers, allowing developers to run AI models for speech recognition, language understanding, and computer vision in their own infrastructure. This addressed enterprise requirements for data sovereignty and low-latency processing that cloud-only solutions could not satisfy. Microsoft also introduced the AI Business School, a free educational resource designed to help business leaders understand AI strategy and implementation. The Azure Machine Learning service received automated hyperparameter tuning and a visual machine learning designer that lowered barriers to model development. New speech services included custom neural voices that could synthesize natural-sounding speech from just 30 minutes of audio samples, opening possibilities for personalized voice assistants. The ONNX Runtime saw improvements that accelerated inference for models trained in various frameworks including PyTorch, TensorFlow, and scikit-learn. Microsoft emphasized responsible AI practices throughout the conference, announcing new fairness assessment tools integrated into Azure Machine Learning. The Azure IoT Edge platform gained AI capabilities, enabling intelligent edge devices to run computer vision models without cloud connectivity. This positioned Microsoft strongly for industrial IoT applications in manufacturing and retail. The partnership with OpenAI continued with news of Azure providing the computational backbone for future OpenAI research. Developers gained access to improved Bot Framework capabilities with better language understanding and conversation management tools.

### Microsoft Build 2019 Azure AI Services Transform Enterprise Development（评分: 9.1/10）
