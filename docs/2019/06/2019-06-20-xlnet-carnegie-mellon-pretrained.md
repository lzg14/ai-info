# CMU与Google提出XLNet：超越BERT的新一代预训练模型

📅 2019-06-20

<!-- 正文开始 -->
## 基本信息

  * **日期** ：2019-06-20
  * **来源** ：卡内基梅隆大学 / arXiv
  * **URL** ：https://arxiv.org/abs/1906.08237
  * **主题** ：自然语言处理，预训练模型，[Transformer](../../glossary/terms/transformer.md)



## 内容摘要

2019年6月，卡内基梅隆大学与Google Brain联合发布XLNet，一种新型自回归预训练模型，在20项NLP任务上超越BERT。XLNet采用"排列语言模型"（Permutation Language Model）解决了BERT因掩码带来的预训练-微调不一致问题，并引入双流[注意力机制](../../glossary/terms/attention-mechanism.md)捕捉位置信息。XLNet在问答、情感分类、文本推理等任务上刷新最优结果，被称为"[BERT](../../glossary/terms/bert.md)之后最重要的NLP模型突破"。它的提出进一步推动了预训练模型的发展，为后续[GPT](../../glossary/terms/gpt.md)系列奠定了技术基础。
