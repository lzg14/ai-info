# Baidu ERNIE 2.0 Surpasses BERT and XLNet

2019年7月，百度正式发布持续学习的语义理解框架ERNIE 2.0，以及基于此框架的预训练模型。继1.0版本在中文任务中全面超越BERT之后，ERNIE 2.0在英文任务方面也取得了全新突破，在共计16个中英文任务上超越了BERT和XLNet，取得了SOTA效果。这是中国AI技术在NLP领域的又一次重要突破。

ERNIE 2.0的核心创新在于其"可持续学习"的理念。该框架支持增量引入词汇（lexical）、语法（syntactic）、语义（semantic）等3个层次的自定义预训练任务，能够全面捕捉训练语料中的词法、语法、语义等潜在信息。与传统的预训练方法不同，这些任务通过多任务学习对模型进行训练更新，每当引入新任务时，该框架可在学习该任务的同时，不遗忘之前学到过的信息。

传统的预训练模型，如BERT，在预训练阶段完成后就固定了模型的知识。而ERNIE 2.0解决了这一问题，它能够不断学习新任务而不灾难性地遗忘旧知识。这对于构建更加智能和灵活的语言模型具有重要意义，也为实际应用中的持续优化提供了可能。

在架构上，ERNIE 2.0同样基于[Transformer](../../../glossary/terms/transformer.md) Encoder，但百度团队设计了更加精细的预训练任务体系。这些任务涵盖了从词法层面的词汇预测，到句法层面的结构分析，再到语义层面的关系理解，形成了一个层次化的学习体系。

百度同时开源了ERNIE 2.0的Fine-tuning代码和英文预训练模型，开发者和研究人员可以在GitHub上获取这些资源。这一开放策略加速了ERNIE在工业界和研究社区的广泛应用，促进了中文NLP技术的进步。

ERNIE 2.0的成功证明了中国科技公司在AI核心技术研发方面的实力，也为中文NLP任务提供了更加强大的工具。随着预训练语言模型在各个行业应用的深入，ERNIE 2.0为搜索引擎、智能问答、内容推荐等应用场景带来了显著的性能提升。
