# 百度 ERNIE 3.0：知识增强的预训练语言模型

百度于2019年发布ERNIE 3.0，这是其知识增强预训练模型的升级版本。ERNIE 3.0在海量文本数据基础上融合大规模知识图谱，显著提升了对语义关系的理解能力。该模型创新性地引入知识模块，增强了模型在知识推理、实体识别等任务上的表现。ERNIE 3.0的发布标志着百度在自然语言处理领域的技术积累达到新高度，为后续文心大模型的发展奠定了基础。
