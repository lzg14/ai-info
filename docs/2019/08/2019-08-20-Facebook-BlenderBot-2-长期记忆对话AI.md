# Facebook BlenderBot 2：具备长期记忆的对话AI

📅 2019-08-20

<!-- 正文开始 -->
Facebook AI于2019年8月发布BlenderBot 2，这是一个具备长期记忆能力的开放域聊天机器人。与初代BlenderBot相比，BlenderBot 2能够通过互联网搜索获取最新信息并进行推理，同时保持对话历史记忆，实现了更持续、更自然的交互体验。该模型融合了检索和生成两种对话技术，展现了构建类人化对话系统的重要方向。BlenderBot 2的开源推动了对话AI研究的进展。

来源：Facebook AI Blog
