# 华为发布昇腾910：全球最强AI处理器

## 基本信息

- **日期**：2019-08-23
- **来源**：华为
- **URL**：https://www.huawei.com/cn/press-events/huawei-releases-ascend-910
- **主题**：AI芯片，算力，硬件

## 内容摘要

2019年8月，华为在深圳发布昇腾910（Ascend 910）AI处理器，号称是全球算力最强的AI处理器。昇腾910基于达芬奇架构，半精度（FP16）算力达256 TFLOPS，整数精度（INT8）算力达512 TOPS，功耗310W。华为同时推出全栈全场景AI解决方案，覆盖芯片、框架、工具链和应用。昇腾910的发布标志着中国在AI芯片领域取得重要突破，与英伟达、谷歌TPU形成竞争格局，对中国AI生态发展具有战略意义。
