fastai v1：简化深度学习的高级API库

入库 2019-10-01

Jeremy Howard和Rachel Thomas创立的fast.ai于2019年10月发布fastai v1版本，这是一个基于PyTorch的高级深度学习API库。fastai的设计理念是让深度学习变得更易于使用，通过提供单一一致的接口，支持计算机视觉、自然语言处理、表格数据等多种应用场景。fastai v1版本针对PyTorch 1.0进行了优化，提供了更直观的高层API。fastai还通过其配套的深度学习课程，推动了AI教育的普及，让更多人能够参与到这个快速发展的领域中。

来源：fast.ai Blog
