# OpenAI -2 完整版：15亿参数语言生成模型发布

📅 2019-11-01

<!-- 正文开始 -->
OpenAI于2019年11月发布了GPT-2完整版，这是一个拥有15亿参数的超大规模语言生成模型。GPT-2能够根据给定文本续写极为逼真的人类语言，其生成质量之高曾被认为可能造成虚假信息传播风险而被部分隐藏。完整版GPT-2的发布展示了大规模预训练语言模型的强大能力，推动了文本生成领域的研究与应用。GPT-2的成功为后续GPT-3的发展奠定了技术基础。
