# 腾讯AI Lab开源PocketFlow：自动化深度学习模型压缩框架

腾讯AI Lab于2019年11月在南京举办的腾讯全球合作伙伴论坛上正式开源PocketFlow项目。这是一个自动化深度学习模型压缩与加速框架，整合多种模型压缩与加速算法并利用强化学习自动搜索最优压缩参数。PocketFlow解决了深度学习模型由于体积太大、计算资源消耗高而难以在移动设备上部署的痛点，极大降低了模型压缩的技术门槛，赋能移动端AI应用开发。该项目的开源展现了腾讯在AI领域推动技术普惠的努力。

来源：腾讯AI Lab
