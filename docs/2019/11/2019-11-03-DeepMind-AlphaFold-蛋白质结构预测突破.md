# DeepMind AlphaFold：在CASP13蛋白质结构预测竞赛中取得突破

📅 2019-11-03

<!-- 正文开始 -->
DeepMind在CASP13（蛋白质结构预测关键评估竞赛）中展示了AlphaFold系统的早期版本，标志着AI驱动生物计算领域的重大突破。AlphaFold使用深度神经网络预测蛋白质的物理结构，其预测准确性显著优于传统方法。该成果于2019年发布，为2020年AlphaFold2在CASP14的里程碑式突破奠定了基础。AlphaFold的成功展示了深度学习在科学发现中的巨大潜力，开启了AI辅助药物研发的新时代。

来源：Nature
