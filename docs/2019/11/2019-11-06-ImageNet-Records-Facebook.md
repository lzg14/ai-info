# Facebook ResNeXt Achieves New ImageNet Classification Record

📅 2019-11-06 | 📎 Facebook AI Research

<!-- 正文开始 -->
## 内容摘要

2019年11月，Facebook AI Research发布了ResNeXt-101 32x48d模型，在ImageNet图像分类基准上创下了新的纪录。该模型达到了前所未有的87.6% top-1准确率，比此前最好的结果提升了1.5个百分点以上。这一成果展示了深度学习在计算机视觉领域的持续进步。

ResNeXt（ResNext）结合了VGG/ResNet的简洁性和Inception模块的多分支结构，提出了一种新的"基数"（cardinality）概念——即每个转换路径的数量。研究发现，增加基数比增加深度或宽度更有效地提升模型性能。Facebook的模型使用32个分组、每个分组48个通道的架构，在ImageNet上实现了最佳性能。

此外，Facebook还发布了使用弱监督学习训练的WSL（Weakly Supervised Learning）模型，这些模型在Instagram上数十亿张带有标签的图片上进行预训练，展现了大规模弱监督预训练在视觉模型中的强大潜力。

ResNeXt的成功表明，尽管深度学习在视觉任务上已经接近人类水平，但通过更好的架构设计和更大规模的训练数据，仍有提升空间。这一成果对迁移学习和模型压缩研究具有重要参考价值。
