OpenAI Releases Full GPT-2 1.5B Model

入库 2019-11-06

2019年11月6日，OpenAI在其博客公布了GPT-2的最大版本（1.5B参数，即15亿参数），并发布了所有相关代码与模型权重。这一发布标志着OpenAI结束了对GPT-2的阶段性发布策略，完整地向研究社区开放了这一当时最大规模的语言模型。

回顾GPT-2的发布历程，OpenAI采取了极为谨慎的分阶段发布策略。2019年2月，OpenAI首次发布GPT-2时，由于担心该技术可能被滥用（例如生成假新闻），只发布了较小的模型版本（124M、355M、774M参数），而最大的1.5B模型则暂缓发布。这一决定引发了AI界的广泛讨论，有人赞赏这种负责任的态度，也有人批评OpenAI背离了"开放"的原则。

在接下来的几个月里，OpenAI逐步释放了更大规模的GPT-2模型。8月，他们发布了774M参数版本，并发布了一份针对这个规模模型的技术报告。经过对模型被滥用风险的评估和观察，OpenAI认为"当初担心的事并没有发生"，于是决定在11月公开完整的1.5B参数模型、程序代码和模型权重。

GPT-2是一种大型语言模型，可以生成逼真的文本段落。其训练数据来自互联网的40GB高质量语料，包含约800万个文档。模型基于Transformer架构，使用自注意力机制来处理文本序列，目标是通过无监督预训练预测下一个单词。

有趣的是，在GPT-2完全公开之前，有人将一篇用GPT-2自动生成的文章投稿到《经济学人》杂志。一位不知情的审稿人给出的评价是："措辞强硬，证据凿凿，但明显缺乏原创性"。这个案例既展示了GPT-2生成文本的高度逼真性，也暴露了其缺乏真正理解能力的局限。

GPT-2的完整发布对NLP研究产生了深远影响。它证明了随着模型规模的增大，语言模型能够涌现出越来越强大的能力，这一思想为后来GPT-3等更大规模模型的诞生奠定了基础。同时，GPT-2的开源也推动了预训练语言模型在各个研究机构的普及。
