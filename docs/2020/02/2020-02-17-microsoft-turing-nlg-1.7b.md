# 微软发布Turing NLGLanguage Model

2020年2月，微软发布了Turing Natural Language Generation (T-NLG) 模型，这是一个拥有17亿参数的巨型语言模型，刷新了当时非混合专家架构语言模型的规模记录。T-NLG基于[Transformer](../../../glossary/terms/transformer.md)解码器架构，在NVIDIA DGX-2集群上训练数周完成。

该模型在多项自然语言处理基准测试中刷新了最优成绩，尤其在问答、摘要生成和阅读理解等任务上表现突出。微软将T-NLG应用于其Office和必应搜索等产品中，显著提升了文本生成质量和响应智能程度。T-NLG的发布加剧了当时大厂之间的大模型军备竞赛，其规模虽小于后来[GPT](../../../glossary/terms/gpt.md)-3的1750亿参数，但证明了单一路线的规模化潜力。微软同时开放了该模型的少样本学习能力测试接口，供研究人员申请使用。
