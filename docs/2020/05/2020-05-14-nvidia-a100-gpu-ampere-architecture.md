# NVIDIA发布A100 GPU：AI算力提升20倍

📅 2020-05-14

<!-- 正文开始 -->
2020年5月14日，NVIDIA CEO黄仁勋在GTC 2020大会上发布了全新Ampere（安培）架构以及基于该架构的A100 GPU。这是当时全球最大的7nm芯片，集成了540亿个晶体管，面积高达826平方毫米，相比上一代Volta架构实现了高达20倍的AI性能提升。

A100 GPU拥有6912个CUDA核心和432个第三代Tensor Core，支持TF32和BF16格式，算力达到2000TOPS。显存方面搭载40GB HBM2，带宽1.6TB/s。由8个A100 GPU组成的NVIDIA DGX A100 AI系统单节点性能达到5 petaflops（每秒千万亿次浮点运算），可同时满足AI训练和推理需求。

A100的发布标志着数据中心级AI计算进入新阶段，对深度学习训练、科学计算、大规模数据分析等应用带来质的飞跃，成为后续[GPT](../../glossary/terms/gpt.md)-3等大模型训练的重要算力基础。
