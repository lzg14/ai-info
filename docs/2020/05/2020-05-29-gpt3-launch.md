# GPT-3 发布：1750亿参数，OpenAI 最大的赌注

📅 2020-05-29

<!-- 正文开始 -->
## 摘要

2020 年 5 月，OpenAI 发布 GPT-3——1750 亿参数的超级语言模型，训练数据量 45TB，训练费用超过 1200 万美元。GPT-3 展示了「大模型」的无监督多任务能力，无需微调即可完成翻译、问答、算数、写作等任务。

## 核心数据

| 指标 | 数值 | |------|------| | 参数规模 | 1750 亿 | | 训练数据量 | 45 TB | | 训练费用 | 约 1200 万美元 | | 上下文窗口 | 2048 tokens |

## 技术突破

**Few-shot 学习：** 与 [BERT](../../glossary/terms/bert.md) 不同，[GPT](../../glossary/terms/gpt.md)-3 不需要微调。只需在 prompt 中给出几个示例，模型即可完成对应类型的任务。

**涌现能力：** 当时业界未预期到，足够大的语言模型会自发涌现出小模型没有的能力。

**API 化：** OpenAI 以付费 API 形式开放，按 token 计费。这是 AI 商业化的重要转折——大模型作为云服务。

## 点评

GPT-3 是 AI 史上的一座分水岭。它证明了「规模」本身就能带来智能涌现，也证明了「大模型+API」的 SaaS 化路径是可行的。
