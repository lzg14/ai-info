OpenAI正式推出-3商用API，开启AI应用新时代

入库 2020-06-11

2020年6月11日，OpenAI正式发布GPT-3商用API，这是该公司首个商业化产品。通过这一API，企业开发者可以直接访问OpenAI最先进的通用人工智能模型，无需等待名单审核。GPT-3作为当时全球最大的语言模型之一，拥有1750亿参数，训练成本高达1200万美元。商用API的发布使得各类企业能够将强大自然语言处理能力集成到自身应用中，覆盖客服系统、视频游戏、在线辅导、心理健康咨询等多个场景。此举标志着AI能力从实验室走向普惠商业应用的关键转折点，也让更多开发者能够以前所未有的低成本调用顶级AI模型进行产品创新。
