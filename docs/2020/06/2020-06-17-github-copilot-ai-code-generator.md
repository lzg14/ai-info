# GitHub Copilot发布：AI驱动的代码补全工具登场

2020年6月17日，GitHub正式发布GitHub Copilot技术预览版，这是全球首个基于AI的大规模代码补全和生成工具。Copilot由GitHub与OpenAI合作开发，底层采用了OpenAI专门为代码任务训练的Codex模型（[GPT](../../../glossary/terms/gpt.md)-3的代码专用变体）。该工具能够根据代码上下文、注释和函数签名自动推断并补全整行甚至整段代码，支持Python、JavaScript、TypeScript、Go、Ruby等多种主流编程语言。

技术预览阶段仅限少量开发者参与测试，但一经发布便引发开发者社区的强烈反响。Copilot的核心能力在于：它不仅能补全简单的重复性代码，还能理解文档字符串、生成测试用例、甚至根据英文注释实现完整函数。开发者反馈显示，Copilot可将某些重复性编码效率提升50%以上。

GitHub CEO Thomas Dohmke 表示，Copilot代表了"AI搭档编程"的开始，AI不再只是工具，而是开发者的协作者。这一产品形态深刻影响了此后AI编程工具的发展方向，也为VS Code等主流IDE的AI扩展生态奠定了基础。
