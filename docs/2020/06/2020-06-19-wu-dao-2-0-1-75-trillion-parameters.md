# 北京智源发布Wu Dao 2.0：1.75万亿参数刷新世界纪录

2020年6月，北京智源人工智能研究院发布了大规模预训练模型Wu Dao 2.0，参数规模达到1.75万亿，成为当时全球最大的超大规模智能模型。Wu Dao 2.0采用了先进的混合专家（MoE）架构，能够根据输入内容动态激活不同的专家网络，在保持模型强大的同时优化计算效率。该模型在文本生成、问答、摘要等多项自然语言处理任务上展现了卓越性能，其发布标志着中国在人工智能大模型领域正式进入世界前列。此举也引发了业界对大模型军备竞赛的广泛讨论，中美两国在超大规模预训练模型领域的竞争日趋激烈。
