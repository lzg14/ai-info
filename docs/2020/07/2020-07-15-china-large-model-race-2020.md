# 2020年大模型军备竞赛：国产大模型密集发布

2020年成为国产大模型发展元年。在OpenAI发布[GPT](../../../glossary/terms/gpt.md)-3、Google推出Meena等国际模型的压力下，中国科技企业纷纷加码大模型研发。百度发布ERNIE 3.0，浪潮信息推出"源1.0"，华为、阿里等企业也陆续发布了自己的超大规模预训练模型。这一年，国内AI大模型呈现爆发式增长态势，各家企业不仅在参数规模上快速追赶国际前沿，更在中文语义理解、跨模态能力等方面进行了针对性优化。大模型军备竞赛的序幕在2020年全面拉开，并延续至后续数年，推动了整个AI行业的技术迭代与生态建设。
