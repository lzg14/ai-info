# EleutherAI正式成立：开源语言模型"草根革命"对抗GPT-3封闭生态

2020年7月，一个名为EleutherAI的开源研究组织正式成立，其核心使命是构建并开源大型语言模型，打破OpenAI对GPT-3的独家垄断。创始成员包括Connor Leahy、Leo Gao和Sid Black等曾参与开源AI社区的活跃研究者。在GPT-3于2020年5月发布并以"独家授权"方式封闭API后，这群研究者发起了开源复现运动。

EleutherAI的成立背景直接指向GPT-3引发的AI资源分配不平等：GPT-3拥有1750亿参数，每天产生45亿词的输出，却被微软独家授权限制，开发者必须申请并付费才能调用接口。EleutherAI认为，语言模型的核心技术不应被少数企业垄断，开源社区有能力复现甚至超越这些模型。

组织成立之初便公布了雄心勃勃的路线图：先期复现GPT-2级别的模型并完全开源，随后扩展至GPT-3级别规模。团队采用分布式协作模式，利用志愿者贡献的算力和开源框架（Pytorch、JAX）进行训练。2020年内，EleutherAI先后开源了GPT-Neo项目（1.3B和2.7B版本），并在下半年推出60亿参数的GPT-J模型，在多个NLP基准上展现了与GPT-3小版本可比的性能。

EleutherAI的成立预示了2020年后大模型开源生态的加速发展，为后来Meta的[LLaMA](../../../glossary/terms/llama.md)、EleutherAI的[GPT](../../../glossary/terms/gpt.md)-NeoX-20B等更大规模开源模型奠定了基础，也成为学术界和独立开发者对抗封闭商业模型的重要力量。
