# EleutherAI开源GPT-Neo对抗OpenAI垄断

2020年8月，非营利研究组织EleutherAI正式发布GPT-Neo开源项目，旨在打造开源版本的GPT系列模型，打破闭源大模型的垄断格局。GPT-Neo 1.0版本包含1.3亿和27亿参数两个规模，基于The Pile数据集训练，完全开源可商用。

EleutherAI由独立研究员和工程师自发组建，他们不满OpenAI在GPT-2上的开源承诺退缩，决定自己动手做开源大模型。GPT-Neo采用与GPT-2相似的[Transformer](../../../glossary/terms/transformer.md)架构，在多项基准测试中达到甚至超越对应规模的[GPT](../../../glossary/terms/gpt.md)-2水平。该项目的开源协议允许商业使用，为无法负担闭源API费用的小开发者和学术研究提供了重要替代方案。EleutherAI后续还推出了GPT-J（6B参数）等更大模型，持续推动开源大模型生态发展。
