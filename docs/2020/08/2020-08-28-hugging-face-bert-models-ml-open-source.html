Hugging Face估值突破十亿美元：开源NLP生态的里程碑

入库 2020-08-28

2020年8月，开源AI公司Hugging Face完成1500万美元A轮融资，估值突破1亿美元，成为开源NLP领域首家独角兽。Hugging Face以其中立的"AI届GitHub"定位，构建了全球最大的预训练模型库和开源Transformers生态系统，吸引了数百万开发者和数千家企业用户。

Hugging Face的核心产品是其开源Python库transformers，该库统一了BERT、GPT-2、T5、ELECTRA等主流预训练模型的接口，大幅降低了NLP模型的使用门槛。2020年，其GitHub仓库星标数呈指数级增长，论文引用量也大幅上升。该平台还成为EleutherAI（致力于开源GPT系列）和BigScience（开源BLOOM）等大型开源项目的核心基础设施。

此轮融资由Lux Capital领投， 红杉资本跟投。Hugging Face CEO Clément Delargue表示，融资将用于扩大团队规模和建设模型托管平台（后来发展为Hub服务）。Hugging Face的成功标志着：开源社区与商业化可以并行不悖，中立平台在AI生态中具有不可替代的价值。

截至2020年底，Hugging Face平台托管的预训练模型超过5万个，成为全球AI开发者共享和部署模型的事实标准，也为后来的大模型开源生态（ EleutherAI、BigScience等）提供了关键基础设施。
