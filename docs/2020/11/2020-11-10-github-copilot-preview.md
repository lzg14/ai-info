# GitHub Copilot 技术预览发布：AI 写代码从梦想走进现实

📅 2020-11-10

<!-- 正文开始 -->
## 摘要

2020 年 11 月，GitHub 联合 OpenAI 正式发布 GitHub Copilot 技术预览版，一个 AI 代码补全插件，集成在 VS Code 中。Copilot 基于 OpenAI 的 Codex 模型，能够根据上下文和注释实时生成代码，被视为「AI 辅助编程」时代的开端。

## 产品形态

  * **插件形式** ：无缝集成进 VS Code、JetBrains IDE
  * **多语言支持** ：Python、JavaScript、TypeScript、Go、Rust、Ruby 等主流语言
  * **功能覆盖** ：从单行补全到完整函数生成，根据注释生成代码，解释现有代码



## 技术基础

Copilot 的核心是 Codex——在 [GPT](../../glossary/terms/gpt.md)-3 基础上使用数十亿行 GitHub 公开代码微调而来的代码专用模型。Codex 最大的改进是能够根据函数签名和上下文「推理」出应填入的代码。

## 产业影响

Copilot 发布后引发开发者社区广泛讨论——一部分开发者认为这是革命性工具（生产力提升 30-50%），另一部分担忧代码版权归属和生成代码的安全漏洞责任问题。

## 点评

GitHub Copilot 是「AI 辅助编程」从概念走向产品的关键一步。它让「AI 写代码」从技术演示变成了日常工具。
