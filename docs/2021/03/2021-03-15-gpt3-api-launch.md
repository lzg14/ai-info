# 3 API 正式开放：大模型即服务时代到来

## 摘要

2021 年 3 月，OpenAI 正式向公众开放 GPT-3 API，允许开发者通过 API 调用这一 1750 亿参数的语言模型。开发者无需训练即可通过自然语言 prompt 完成翻译、摘要、代码生成、对话等任务，标志着「大模型即服务」（Model-as-a-Service）模式的商业化落地。

## API 设计理念

GPT-3 API 采用了独特的「Text in, Text out」接口——开发者只需提供一段文字描述（prompt），模型即可返回完成的任务结果。这种设计极大降低了 AI 的使用门槛。

## 商业模式

OpenAI 采用了按 token 计费的商业模式，迅速获得了数千家企业的青睐。AI21 Labs、Cohere 等竞争对手相继出现，「大模型 API 经济」开始形成。

## 生态影响

GPT-3 API 的开放催生了数百家基于大模型的初创公司，涵盖写作助手、代码生成、法律文档、医疗记录等垂直场景。

## 点评

GPT-3 API 的开放，是 AI 商业化的重要转折。它证明了大模型不仅能「炫技」，更能「赚钱」。从此，AI 创业的门槛大幅降低。
