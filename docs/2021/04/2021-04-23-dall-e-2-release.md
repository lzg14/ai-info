# OpenAI发布DALL-E 2：多模态AI图像生成进入新纪元

2021年4月，OpenAI正式发布DALL-E 2，标志着AI图像生成能力实现质的飞跃。作为初代DALL-E的升级版本，DALL-E 2采用LATENT [Diffusion Model](../../../glossary/terms/diffusion-model.md)（潜空间扩散模型）架构，大幅提升了图像生成的分辨率、质量和速度。

DALL-E 2的核心突破在于：可基于文本描述生成高度匹配的文字创作图像，支持对生成图像进行风格迁移、局部修改和多版本迭代。其遵循的安全策略包括去除暴力色情内容、拒绝生成真实人脸图像等技术伦理考量。

DALL-E 2的发布引发行业震动，催生了Midjourney、Stable Diffusion等竞争产品，推动AI生成内容（AIGC）从研究走向大规模商业应用，成为2021年最受瞩目的AI里程碑之一。
