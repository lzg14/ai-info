# 华为云发布盘古大模型系列：面向行业应用的千亿级NLP模型

📅 2021-04-25

<!-- 正文开始 -->
2021年4月，华为云在开发者大会上正式发布盘古系列大模型，其中NLP大模型参数规模达千亿级别。盘古大模型定位为"行业AI应用底座"，旨在降低AI在各行业场景的应用门槛。

盘古NLP模型采用[Transformer](../../glossary/terms/transformer.md)架构，针对中文语言特性进行深度优化，在中文理解、生成和推理任务上表现领先。与通用大模型不同，盘古强调与行业场景结合，已在气象预测、药物研发、金融分析等领域展开试点应用。

华为云同步开源了盘古模型的部分技术能力，推动国产大模型生态建设。此举被视为中国科技企业在大型语言模型领域的重要布局，与百度文心、阿里M6形成竞争态势。
