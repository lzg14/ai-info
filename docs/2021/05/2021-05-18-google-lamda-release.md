# Google发布LaMDA：面向开放域对话的顶尖语言模型

📅 2021-05-18

<!-- 正文开始 -->
2021年5月，Google在I/O大会上发布LaMDA（Language Model for Dialogue Applications），这是一款专注于开放域对话场景的大型语言模型。LaMDA基于Google的Decoder-only [Transformer](../../glossary/terms/transformer.md)架构，参数量高达1370亿，在对话流畅度、多轮交互能力和事实一致性上实现了显著突破。

LaMDA的核心特点在于能够进行"合理且有趣"的对话——不仅仅是回答问题，而是像真人一样参与有深度、有内涵的讨论。Google展示了LaMDA在角色扮演、创意构思等场景中的能力，其逼真的交互体验引发业界对AGI可能性的广泛讨论。

该模型的发布标志着对话AI从"问答系统"向"智能对话伙伴"的重要转折，同时也引发了关于AI伦理和安全的新一轮探讨。
