# 百度 Apollo RT6 发布：L4 级自动驾驶成本降至 25 万元

📅 2021-08-18

<!-- 正文开始 -->
## 摘要

2021 年 8 月，百度在「2021 百度世界大会」上发布 Apollo RT6——第六代量产无人车。RT6 基于 Apollo 自动驾驶技术重大突破，具备城市复杂道路的完全无人驾驶能力（L4 级），成本仅为 25 万元人民币，约为上一代的一半。

## 核心参数

| 项目 | 参数 | |------|------| | 自动驾驶级别 | L4（完全无人驾驶） | | 成本 | 约 25 万元 | | 传感器 | 激光雷达 + 摄像头 + 毫米波雷达 | | 生产时间 | 2023 年（规划） |

## 战略意义

百度 Apollo RT6 的低成本量产，标志着 Robotaxi 商业化进程迈出关键一步。25 万的成本已经低于中国中档燃油车的价格，意味着 Robotaxi 在经济性上具备了与网约车竞争的可能。

## 点评

百度 Apollo 正在走一条与特斯拉不同的路径——直接做 L4 无人驾驶，而非 L2 渐进式推进。两条路径的竞争将是未来十年自动驾驶领域的主线之一。
