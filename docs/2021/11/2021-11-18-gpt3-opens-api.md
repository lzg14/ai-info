# OpenAI Removes GPT-3 Waitlist Opens API Access

📅 2021-11-18

<!-- 正文开始 -->
On November 18, 2021, OpenAI announced the removal of the GPT-3 waitlist, making its API fully accessible to developers in supported countries. This marked a significant milestone in democratizing access to one of the world's most powerful language models. After a year of careful API improvements—including the Instruct series models that follow human guidance, dedicated endpoints for more truthful question answering, and a free content filter to help developers reduce misuse by filtering adult and violent content—OpenAI determined that sufficient safety measures were in place to open the API to all eligible developers immediately.

GPT-3, originally launched in May 2020, is a neural language model with 175 billion parameters capable of generating human-like text and code. Its generated text is so high-quality that it is often difficult to distinguish from human-created content. The removal of the waitlist means developers worldwide can now register and start experimenting with the API without undergoing the previous review process. This change signals OpenAI's confidence that GPT-3 is sufficiently safe and that the company can adequately monitor the model for broader dissemination.

In the months following this opening, OpenAI further enhanced the API by allowing developers to fine-tune GPT-3 for their specific use cases. Customized GPT-3 models can better serve applications requiring deep language understanding, delivering higher quality content output across tasks and workloads. This fine-tuning capability significantly improved accuracy—sometimes more than doubling it for specific applications. The combination of open access and customization options has enabled developers worldwide to build a wide range of applications, from writing assistants to code generation tools, fundamentally changing how businesses and individuals interact with AI-powered language processing.
