# DeepMind发布Gato多模态AI代理模型

DeepMind发布了Gato，一个通用的多模态AI代理模型。Gato能够处理文本、图像、机器人控制等多种任务，使用单一的模型架构和权重即可完成不同领域的任务。该模型包含1.2亿参数，通过序列化不同的多模态数据并用[Transformer](../../../glossary/terms/transformer.md)进行处理。Gato的发布展示了通用AI代理的可能性，引发了关于通用人工智能发展路径的讨论。
