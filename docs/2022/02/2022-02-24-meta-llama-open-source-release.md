# Meta发布开源大语言模型

📅 2022-02-24

<!-- 正文开始 -->
Meta（原Facebook）发布了LLaMA系列开源大语言模型，包含7B到65B参数版本。LLaMA虽然规模小于[GPT](../../glossary/terms/gpt.md)-3，但在众多基准测试中表现优异。Meta选择开源模型权重，推动了学术界对大语言模型的研究。LLaMA的开源引发了对AI开放性的广泛讨论，也为后续开源社区模型（如LLaMA后续变体）的发展奠定基础。
