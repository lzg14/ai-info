# OpenAI 全面开放 -3 API：开发者可自主微调模型

## 摘要

2022 年 3 月，OpenAI 宣布全面开放 GPT-3 API，并新增「微调」（Fine-tuning）功能，允许开发者使用自有数据对 GPT-3 进行专项微调，显著提升特定任务的表现。这意味着企业可以拥有自己定制版的 GPT-3。

## 微调功能

**自定义模型：** 开发者可以上传自己的训练数据，OpenAI 在原始 GPT-3 基础上进行微调，生成专门适配特定任务的新模型。

**使用场景：** 客服对话、医疗记录摘要、法律文档处理、代码补全等垂直领域。

**定价：** 微调后的模型按 token 计费，与标准 GPT-3 API 相同。

## 生态影响

GPT-3 微调功能的开放，让中小企业无需从头训练大模型，就能拥有领域专属的语言模型。这催生了大量垂直 AI 创业公司。

## 点评

GPT-3 微调 API 的开放，是「大模型平台化」的重要一步。它让 AI 能力从「少数大公司专属」变成了「人人可用」。
