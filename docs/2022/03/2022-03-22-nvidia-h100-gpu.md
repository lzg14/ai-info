# NVIDIA H100 GPU Architecture Launch

NVIDIA H100 GPU是NVIDIA于2022年3月发布的下一代数据中心GPU，采用了全新的Hopper架构。H100是当时世界上最强大的GPU，专为人工智能训练和推理任务设计，代表了GPU计算能力的重大飞跃。它的发布进一步巩固了NVIDIA在AI芯片领域的绝对领先地位，同时也为全球AI研究和企业应用提供了更强大的算力基础。

H100 GPU基于台积电4nm工艺制造，晶体管数量达到800亿个，相比前代A100 GPU的542亿晶体管有显著增加。H100引入了多项硬件级创新，包括第四代Tensor Cores（张量核心）、[Transformer](../../../glossary/terms/transformer.md)引擎、DPX指令（专门用于动态规划算法）以及改进的NVLink互联技术。H100的FP16算力达到3958 TFLOPS，是A100的约3倍，而在使用FP8精度时，推理性能更可提升6倍。

H100架构的一个重要特性是对Transformer模型的大幅优化。Transformer是GPT、BERT等现代大语言模型的核心架构，而H100内置的Transformer引擎可以动态选择最佳的数值精度（FP16或FP8），自动加速Transformer模型的训练和推理过程。此外，H100支持新的DPX指令集，可以将动态规划算法的速度提升40倍，这对生物信息学（如蛋白质结构预测）和路由优化等应用有重要意义。

H100还引入了MIG（Multi-Instance GPU）技术的升级版本，允许将单个H100划分为最多7个独立的GPU实例，每个实例可以独立运行不同的工作负载。这对于云计算服务商特别有价值，可以更灵活地利用GPU资源。H100还支持PCIe Gen5和NVLink第四代，互联带宽大幅提升，使得构建大规模GPU集群更加高效。

H100的发布对AI行业产生了深远影响。在大模型训练领域，H100使得训练[GPT-4](../../../glossary/terms/gpt.md)等超大规模模型成为可能或大幅缩短训练时间。2022年也是大语言模型爆发的一年，多个科技巨头宣布训练或部署基于H100的AI系统。H100的强劲需求导致全球GPU短缺，科技公司纷纷向NVIDIA订购，H100一度成为地球上最抢手的芯片。

NVIDIA还在2022年推出了H100的SXM和PCIe两种规格版本，以适应不同的部署场景。SXM版本通过NVIDIA NVLink连接，适用于DGX H100和HGX H100系统，提供更高的带宽；PCIe版本则通过标准的PCIe接口连接，更易于集成到现有数据中心。H100还支持NVIDIA的AI企业软件栈，包括TensorRT、 Triton推理服务器等工具，为企业部署AI应用提供完整的解决方案。
