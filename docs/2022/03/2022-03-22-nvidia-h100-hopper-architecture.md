# NVIDIA推出H100 GPU Hopper架构

NVIDIA发布了基于Hopper架构的H100 GPU，这是专门为AI和HPC工作负载设计的新一代数据中心GPU。H100引入了[Transformer](../../../glossary/terms/transformer.md)引擎，显著加速了大模型训练。新架构相比上一代A100在AI训练和推理上有数倍性能提升。H100的发布标志着AI算力进入新阶段，推动了大语言模型和生成式AI的快速发展。
