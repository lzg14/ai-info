# NVIDIA 发力 AI 企业市场：推出 Base Command Enterprise 平台

📅 2022-04-14

<!-- 正文开始 -->
## 摘要

2022 年 4 月，NVIDIA 推出 Base Command Enterprise 平台——一款面向企业的 AI 训练和推理管理平台，支持企业在数据中心和多云环境中统一管理 NVIDIA GPU 集群。配合 H100 GPU 的发布，NVIDIA 正在从「GPU 供应商」转型为「AI 基础设施平台公司」。

## 核心功能

**多集群管理：** 统一管理 NVIDIA A100/H100 集群，支持跨本地数据中心和云端（AWS、Azure、GCP）的资源调度。

**MLOps 集成：** 内置对 PyTorch、TensorFlow 的优化支持，支持容器化部署和模型版本管理。

**enterprise 支持：** 提供 SLA 保障、企业级安全和企业单点登录（SSO）。

## 市场背景

随着 [GPT](../../glossary/terms/gpt.md)-3、AlphaCode 等超大模型的出现，企业对 AI 基础设施的需求急剧增长。NVIDIA 的软件栈从 GPU 硬件向上延伸，试图打造类似 VMware 在服务器虚拟化领域的平台统治力。

## 点评

NVIDIA 的战略很清楚：硬件是护城河，软件才是壁垒。Base Command Enterprise 是 NVIDIA「软硬一体化」AI 平台战略的核心产品。
