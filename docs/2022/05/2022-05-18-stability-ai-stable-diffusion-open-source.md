# Stability AI发布Stable Diffusion开源模型

Stability AI发布了Stable Diffusion，这是一个开源的文本到图像生成模型。相比DALL-E 2，Stable Diffusion可以本地运行，降低了AI图像生成的门槛。该模型迅速在社区流行，引发了AI艺术创作的热潮。开源策略使Stable Diffusion成为最受欢迎的图像生成模型之一，推动了AI创意工具的普及。
