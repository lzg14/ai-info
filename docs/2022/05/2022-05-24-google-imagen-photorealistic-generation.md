# Google发布Imagen高保真图像生成模型

Google发布了Imagen，这是一个文本到图像的高保真生成模型。Imagen结合了大型语言模型和扩散模型，在图像质量和对文本理解方面展现出卓越能力。虽然未公开商业发布，但Google展示了AI生成照片级真实感图像的可能性。Imagen被认为是当时最先进的文本到图像模型之一。
