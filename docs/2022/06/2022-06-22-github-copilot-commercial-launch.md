# GitHub Copilot 正式商用：超 120 万开发者使用，AI 编程成标配

## 摘要

2022 年 6 月，GitHub 宣布 GitHub Copilot 正式脱离技术预览版，向所有开发者开放商用。订阅定价为每月 10 美元（或每年 100 美元）。GitHub 数据显示，上线一年内已有超过 120 万开发者使用 Copilot，编写代码中约 46% 的代码由 Copilot 自动补全。

## 功能升级

**多语言支持：** Copilot 现已支持 Python、JavaScript、TypeScript、Go、Ruby、Java 等数十种编程语言。

**IDE 全覆盖：** 除 VS Code 外，还支持 JetBrains 全家桶（IntelliJ、PyCharm）、Neovim 等主流 IDE。

**注释生成代码：** 开发者可直接用自然语言写注释，Copilot 根据注释生成完整函数实现。

**多行补全：** 支持一次性补全整个函数体，而非逐行补全。

## 开发者反馈

调查显示，Copilot 用户中：
- 60% 认为 Copilot 提高了生产力
- 75% 觉得 Copilot 节省了查阅文档的时间
- 47% 的代码由 Copilot 补全（该数据由 GitHub 自己报告，存在争议）

## 争议

部分开发者对 Copilot 的代码质量和版权问题提出质疑：
- 训练数据来自开源代码，是否存在版权风险？
- AI 补全的代码归属权如何界定？

## 点评

GitHub Copilot 的正式商用，标志着 AI 编程从「新奇玩具」正式进入「生产力工具」阶段。2022 年是 AI 编程的商用元年。
