# GitHub Copilot正式公开发售

GitHub Copilot正式向所有开发者公开发售，这是AI辅助编程的里程碑事件。Copilot由OpenAI Codex驱动，能够在编写代码时提供智能补全建议。订阅价格为每月10美元或每年100美元。GitHub报告显示，使用Copilot的开发者编程效率显著提升。Copilot的正式发布标志着AI编程工具进入商业化阶段。
