# OpenAI发布Codex编程模型API

OpenAI通过API发布了Codex，这是将代码编写能力商业化的重要步骤。Codex是GitHub Copilot背后的技术基础，能够理解代码上下文并生成高质量代码片段。开发者可以通过OpenAI API将Codex能力集成到自己的应用中。Codex的发布扩展了AI编程工具的应用范围。
