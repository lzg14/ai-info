# DeepMind扩展AlphaFold蛋白质数据库

DeepMind宣布将AlphaFold蛋白质结构数据库扩展至2亿个蛋白质结构，覆盖了几乎所有已知蛋白质。该数据库免费向全球科研人员开放。AlphaFold自2021年发布以来，已成为结构生物学领域的重要工具。大规模数据库的开放加速了生命科学研究和药物发现进程。
