# 微软向 OpenAI 追加投资 100 亿美元，AI 商业化按下加速键

## 💰 科技史上最大投资之一

1月23日，微软宣布向 OpenAI 追加投资数十亿美元，加上此前已投入的约 30 亿美元，总额累计超过 100 亿美元。这是科技史上规模最大的单笔投资之一，标志着全球 AI 商业化进程正式进入"大厂军备竞赛"阶段。


微软与 OpenAI 的合作模式在当时已十分清晰：
- **算力支持**：Azure 云为 OpenAI 提供训练所需的巨额算力
- **商业转化**：OpenAI 的 GPT 模型能力通过 Azure OpenAI 服务向企业客户输出
- **产品整合**：[GPT-4](../../../glossary/terms/gpt.md) 相继接入必应搜索、Office 办公套件

## 📈 行业影响

这笔投资直接带动了全球 VC 对 AI 领域的狂热追捧。国内阿里、百度、腾讯等大厂迅速跟进，纷纷加码大模型投入。一时间，"千模大战"成为 2023 年中国 AI 市场的主旋律。

## 💬 各方评价

微软 CEO 纳德拉表示："我们与 OpenAI 的合作，旨在将 AI 的力量交到每个人手中。"而资本市场则用脚投票——微软股价在消息公布后一路上扬，成为当年最受资金追捧的科技股之一。
