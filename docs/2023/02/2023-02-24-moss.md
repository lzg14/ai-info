# 复旦大学发布 MOSS：国内首个类  对话模型

## 🇨🇳 中国版"ChatGPT"开山之作

2月24日，复旦大学邱锡鹏教授团队正式发布 MOSS 对话式大型语言模型，并面向公众开放内测。MOSS 的命名致敬了《流浪地球》中的 AI MOSS，成为国内首个对标 ChatGPT 的开源对话模型。

## 🔧 技术特点

MOSS 是国内首个支持插件调用能力的对话模型，能够使用搜索引擎、图像生成模型、方程求解器等外部工具，这在当时国内模型中是领先的能力。MOSS 的开源也推动了国内大模型生态的加速发展。

## 📈 意义

MOSS 的发布被视为"中国大模型元年"的重要标志之一。此后，百度文心一言、阿里通义千问、智谱 ChatGLM 等产品相继问世，中国正式进入"百模大战"时代。
