# GitHub Copilot X发布：AI编程助手全面升级

GitHub发布Copilot X，将[GPT-4](../../../glossary/terms/gpt.md)驱动的AI能力引入编程工作流的方方面面。Copilot X不仅限于代码补全，还新增了聊天界面、语音控制、文档问答等交互方式。开发者可以通过自然语言询问API用法、调试问题，或让AI解释代码逻辑。Copilot X还支持pull request总结、BIS大纲生成等高级功能。OpenAI最新模型为Copilot X提供了更强大的上下文理解和推理能力，使AI编程助手真正成为开发者的得力助手。
