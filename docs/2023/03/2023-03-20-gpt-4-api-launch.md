# OpenAI推出GPT-4 API：多模态能力开放

📅 2023-03-20

<!-- 正文开始 -->
OpenAI正式向开发者开放GPT-4 API，标志着GPT-4多模态能力进入实用化阶段。开发者现在可以通过API调用GPT-4强大的语言理解和生成能力，以及图像分析功能。GPT-4在推理能力、指令遵循、创造力等方面显著优于[GPT-3.5](../../glossary/terms/gpt.md)，同时保持了较高的稳定性。API的开放催生了大量基于[GPT-4](../../glossary/terms/gpt.md)的应用创新，从智能客服到代码助手，从内容创作到教育辅助，[GPT](../../glossary/terms/gpt.md)-4正在重塑各行各业的AI应用格局。
