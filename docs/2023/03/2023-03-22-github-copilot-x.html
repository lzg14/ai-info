GitHub Copilot X 发布： 驱动 AI 结对编程时代

入库 2023-03-22

2023年3月22日，全球最大开发者社区GitHub正式发布Copilot X，将GPT-4能力深度融入编程工具链，标志着AI辅助编程从"代码补全"升级为"智能结对编程"。新版本不仅延续代码建议功能，更新增对话交互、语音输入、PR处理、命令行辅助等能力，覆盖软件开发的全生命周期。

Copilot X基于GPT-4模型打造，在对话功能中调用GPT-4进行深度理解，代码撰写则使用响应更快的Codex模型。用户可通过自然语言与AI交流，获得代码解释、漏洞检测、测试生成、项目问答等服务。GitHub将其定位为"AI软件开发的愿景"，期望Copilot成为整个程序开发周期的AI助理。

此前GitHub Copilot已有超过5000个企业客户和100万开发者使用，数据显示开发者编程速度提升55%，46%的代码来自AI辅助。Copilot X的发布进一步拓展能力边界，涵盖Pull Request处理、代码审查等环节，并将聊天与语音功能整合进VS Code和Visual Studio IDE。目前个人版月费10美元，企业版19美元，Copilot Chat已于年底向所有用户免费开放。
