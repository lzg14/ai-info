# Plugins发布：AI原生应用生态启航

OpenAI正式推出Chat[GPT](../../../glossary/terms/gpt.md) Plugins（插件）功能，标志着AI助手从单一对话工具向平台生态转型。插件机制允许ChatGPT连接第三方服务，获取实时信息、执行具体操作。通过插件，用户可以让ChatGPT查询航班、预订餐厅、访问数据库、执行代码等。首批上线的插件涵盖电商、办公、生产力等多个领域。ChatGPT Plugins的发布被业界视为AI原生应用生态的开端，科技巨头纷纷跟进推出各自的AI插件平台。
