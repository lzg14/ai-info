# Stable Diffusion XL 1.0正式发布：AI图像生成新标杆

📅 2023-04-17

<!-- 正文开始 -->
Stability AI发布Stable Diffusion XL（SDXL）1.0版本，树立了开源图像生成模型的新里程碑。SDXL采用了全新的架构设计，在图像质量、细节表现、风格多样性等方面显著优于前代版本。该模型能够生成高达1024×1024分辨率的逼真图像，对人物、风景、物体等各类场景的理解更加精准。SDXL的开源发布延续了Stability AI推动AI民主化的理念，让全球开发者能够免费使用这一强大的图像生成工具。
