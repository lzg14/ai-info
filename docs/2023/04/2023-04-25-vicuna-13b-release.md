# Vicuna 13B发布：开源对话模型的新选择

LMSYS发布Vicuna 13B开源对话模型，这是基于LLaMA微调的高质量对话系统。Vicuna通过从ShareGPT获取的用户共享对话数据进行训练，在多项评估中展现出接近[GPT-3.5](../../../glossary/terms/gpt.md)的表现。该模型的训练成本仅约300美元，体现了开源社区在模型优化方面的创新能力。Vicuna的发布受到广泛关注，其训练方法和数据收集流程为后续开源对话模型提供了重要参考，推动了开源大模型生态的快速发展。
