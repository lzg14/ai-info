AI Agent 浪潮来袭：AutoGPT 引领自主任务执行新范式

入库 2023-04-28

2023 年 4 月，一款名为 AutoGPT 的开源工具在 GitHub 迅速走红，仅用两周时间便获得超过 10 万星标。AutoGPT 展现了一种全新的 AI 使用范式——让 GPT-4 自动分解任务、调用工具、执行多步骤复杂目标，而无需人类逐步干预。

核心创新：ReAct 模式

AutoGPT 的核心技术是基于"ReAct"（Reasoning + Acting）的自主 Agent 架构。模型不再仅仅"回答问题"，而是： 1. 理解一个复杂目标（如"帮我在亚马逊找到最便宜的无线耳机"） 2. 自动拆解为多个子任务 3. 调用搜索、浏览网页、执行代码等工具 4. 自我反思并调整下一步行动

后续影响

AutoGPT 的爆红直接催生了 GPT-4 Plugins、ChatGPT Code Interpreter 等 OpenAI 官方 Agent 工具的加速推出，也奠定了 2023 下半年"Agent 元年"的技术基础。
