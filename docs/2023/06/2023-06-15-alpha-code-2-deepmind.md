# DeepMind发布AlphaCode 2：编程能力再创新高

📅 2023-06-15

<!-- 正文开始 -->
DeepMind发布AlphaCode 2，这是基于[Gemini](../../glossary/terms/gemma.md)模型打造的下一代编程AI系统。AlphaCode 2在编程竞赛中展现出超越大多数人类选手的实力，能够解决更加复杂和创新的算法问题。该模型采用了先进的搜索和推理机制，在生成代码的同时进行自我验证和优化。AlphaCode 2的发布标志着AI编程能力达到新的高度，对于提升软件工程师工作效率、辅助算法教学等场景具有重要价值。
