# ：2023年最热LLM应用开发框架

LangChain 是一款帮助在应用程序中使用大型语言模型（LLM）的编程框架，于 2022 年 10 月以 Python 工具起步，2023 年 2 月增加 TypeScript 支持，至 4 月已支持 Node.js、浏览器、Cloudflare Workers、Vercel/Next.js、Deno 和 Supabase Edge Functions 等多种 JavaScript 环境。该框架为开发者提供了一套完整的工具、组件和接口，可简化创建由 LLM 驱动的应用程序的过程，适用于文档分析与摘要、聊天机器人和代码分析等场景。随着 AI 应用需求激增，LangChain 在 2023 年迅速成为开发者构建 LLM 应用的首选框架，推动了 AI 应用开发的大众化进程。
