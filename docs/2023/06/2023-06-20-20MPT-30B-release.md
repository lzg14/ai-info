# MosaicML发布MPT-30B：商业可用的开源大模型

MosaicML发布MPT-30B（MPT系列新旗舰），这是一款真正可以免费商用的大语言模型。MPT-30B经过3.2万亿tokens的高质量数据训练，在保持高性能的同时完全开放商业使用权限。该模型采用了FlashAttention和Fused kernels等优化技术，推理效率显著提升。MPT-30B的发布为企业用户提供了绕过OpenAI等闭源服务的替代选择，推动了大模型商业化应用的发展。
