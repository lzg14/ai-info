ChatGPT Plugins 开放：AI 的"App Store 时刻"

入库 2023-06-22

6月22日，OpenAI 正式向所有 Plus 用户开放 ChatGPT Plugins 功能，这是 ChatGPT 首次能够实时访问互联网、执行外部操作。Plugins 相当于给 ChatGPT 装上了"手"和"脚"，让它能够真正"做事"而非仅仅"回答问题"。

首批插件生态

Plugins 上线时已接入超过 70 个应用，包括：

  • 浏览插件：实时搜索互联网，解决 ChatGPT 知识截止日期问题
  • Code Interpreter：在沙盒环境中执行代码、生成图表、分析数据
  • 第三方插件：Expedia（旅行）、OpenTable（订餐）、Wolfram（数学计算）等

战略意义

Plugins 的推出被视为 AI 行业的"App Store 时刻"——OpenAI 通过构建插件生态，将 ChatGPT 从一个聊天工具转变为真正的"AI 操作系统"，开发者可以在其上构建各类 AI 应用。
