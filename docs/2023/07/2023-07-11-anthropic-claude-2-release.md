# Anthropic 发布 2 大语言模型：性能对标 GPT-4，支持 10 万 token 上下文

2023年7月11日，人工智能公司 Anthropic 正式发布了全新的大语言模型 Claude 2，该模型在编程、数学、推理等方面相比前代版本有显著提升，性能直接对标 OpenAI 的 [GPT](../../../glossary/terms/gpt.md)-4。Claude 2 允许用户输入长达 10 万个 token 的上下文窗口，这意味着它可以一次处理数百页的技术文档甚至整本书籍的内容。在律师资格考试的多选题测试中，Claude 2 取得了 76.5% 的得分，高于 Claude 1.3 的 73.0%。用户可以通过 API 以及全新的公开测试网站 claude.ai 访问 Claude 2，该模型还支持上传 PDF、TXT、CSV 等格式的文件，单个文件最大 10MB，最多可上传 5 个文件。Claude 2 的知识库截止时间为 2023 年初。
