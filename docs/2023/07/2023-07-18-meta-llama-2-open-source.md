# Meta发布 2：史上最强开源大语言模型

📅 2023-07-18

<!-- 正文开始 -->
Meta正式发布Llama 2开源大语言模型，掀起开源AI社区的革命浪潮。Llama 2包含7B、13B、70B三个参数规模的版本，并在高达2万亿tokens的数据上进行预训练，性能大幅超越一代Llama。更重要的是，Meta此次允许Llama 2免费用于商业研究目的，这一决策深刻影响了开源AI生态的竞争格局。Llama 2的发布让更多企业、研究机构和个人开发者能够基于强大的开源基座模型进行二次开发，加速了AI技术的普及与创新。
