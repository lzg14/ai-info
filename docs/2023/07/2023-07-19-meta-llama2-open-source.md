# Meta发布 2开源大模型：免费可商用，与微软Azure深度合作

📅 2023-07-19

<!-- 正文开始 -->
2023年7月19日，Meta AI正式发布LLaMA 2开源大语言模型，这是继2023年2月首次发布LLaMA后的一次重大升级。LLaMA 2包含70亿、130亿和700亿参数三种规模的模型，与微软Azure云服务合作，向全球开发者首发基于LLaMA 2的云服务，同时宣布与高通合作，使LLaMA 2能在高通芯片上运行，打破英伟达、AMD处理器对AI产业的垄断。

与初代LLaMA相比，LLaMA 2训练所用的token翻了一倍至2万亿，上下文长度也翻倍至4096个token，整体fine-tuning过程使用了100万人工标记数据。LLaMA 2最重大的变化在于开源协议——允许免费用于研究和商业用途，这一举措被Meta首席AI科学家杨立昆认为将改变大模型市场格局。LLaMA 2的发布对AI社区意义重大，为开发者和企业提供了强大的开源选择。
