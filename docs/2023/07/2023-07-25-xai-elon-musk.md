# xAI成立： Elon Musk进军AI领域

Elon Musk宣布成立xAI人工智能公司，正式进军大语言模型领域。xAI的使命是理解宇宙的真实本质，致力于构建安全的AGI系统。Musk表示将开发"最大程度好奇心"的AI系统，而非刻意迎合人类的AI。xAI团队汇集了来自DeepMind、OpenAI等机构的多位AI专家。xAI的成立使Musk同时拥有特斯拉、SpaceX、Twitter等科技资产，形成独特的AI战略布局。
