# Stable Diffusion XL 1.0正式发布：开源图像生成进入新纪元

2023年7月26日，Stability AI 正式发布 Stable Diffusion XL 1.0（SDXL 1.0），这是开源文生图领域的重大里程碑。SDXL 1.0 以35亿活跃参数、66亿总参数的大模型规模，在图像质量、细节表现和文本理解能力上实现了质的飞跃。该模型支持生成1024×1024高分辨率图像，在色彩还原、光影效果和人物姿态方面大幅超越前代版本。SDXL 1.0 采用 Apache 2.0 开源许可，任何人均可免费商用。Stability AI 同时发布了配套的 CLIP 视觉编码器和精调工具链，降低了二次开发的门槛。SDXL 的发布标志着开源图像生成模型首次在视觉效果上可比肩 Midjourney v5、DALL-E 3 等闭源商业产品，对 AI 图像创作生态产生了深远影响。
