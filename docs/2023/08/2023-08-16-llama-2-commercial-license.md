# 2商用许可调整：Meta开源战略深化

Meta宣布调整Llama 2商用许可条款，进一步放宽开源模型商业使用限制。根据新许可，月活跃用户不超过7亿的应用可免费使用Llama 2，超过这一门槛才需与Meta商讨商业授权。这一决策极大降低了中小企业和创业公司使用强大开源模型的门槛，被视为Meta构建以自身为中心的开源AI生态的关键一步。微软、亚马逊等云服务商迅速跟进，在各自平台上提供Llama 2托管服务。
