# Ideogram AI：专注文字图像生成的AI独角兽诞生

📅 2023-08-23

<!-- 正文开始 -->
2023年8月23日，总部位于多伦多的AI创业公司Ideogram AI正式宣布成立，并完成1650万美元种子轮融资，由a16z和Index Ventures领投，AIX Ventures、Golden Ventures、Two Small Fish Ventures等机构参投。投资人名单还包括Uber首席科学家Raquel Urtasun、谷歌AI负责人Jeff Dean、伯克利大学教授Pieter Abbeel、GitHub创始人Tom Preston-Werner等行业知名人士。

Ideogram由多位前Google Brain研究员创立，其核心产品是专注于文字与图像融合的AI图像生成模型。与Midjourney、Stable Diffusion等通用图像生成工具不同，Ideogram的独特优势在于其对文字细节的精准把控——能够将复杂文字自然地嵌入图像中，生成海报、Logo、设计图等带文字的视觉内容，且文字效果清晰规范。这一差异化定位使其在AI图像竞争激烈的市场中迅速获得关注。

Ideogram于2023年8月正式推出在线平台ideogram.ai，用户可通过Google账号登录免费使用。该平台支持多种艺术风格的图像生成，其Magic Prompt功能可自动优化提示词，深受设计师和创意工作者好评。凭借强大的文字渲染能力和垂直应用场景，Ideogram被视为AI图像生成领域的后起之秀。
