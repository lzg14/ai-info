# Hugging Face完成2.35亿美元D轮融资，估值达45亿美元

开源AI模型库公司Hugging Face于2023年8月宣布完成2.35亿美元D轮融资，由Salesforce旗下投资机构Salesforce Ventures领投，Google、亚马逊、英伟达、AMD、高通、英特尔、IBM等科技巨头以及知名风险投资机构Sound Ventures等跟投。本轮融资完成后，Hugging Face估值达到45亿美元，较2022年5月C轮融资时的20亿美元估值翻倍有余。

Hugging Face成立于2016年，其平台类似于软件开发领域的GitHub，被广泛用于托管代码、管理训练数据集并与他人协作。目前平台托管超过10万个开源AI模型，50万个模型和25万个数据集，拥有超过1.5万家企业用户，包括英特尔、高通、辉瑞、彭博社等不同行业的头部企业。其推出的BigScience研究计划已构建了世界上最大的开源自然语言处理模型之一。

本轮融资将进一步加强Hugging Face作为领先开源和开放科学AI平台的地位，助力其持续扩展模型库生态并深化企业级服务能力。
