# OpenAI推出DALL-E 3：深度集成的图像生成模型

OpenAI发布DALL-E 3图像生成模型，实现了与Chat[GPT](../../../glossary/terms/gpt.md)的深度集成，用户可以通过自然语言对话的方式创建和修改图像。DALL-E 3在图像质量、 prompt理解能力方面实现了显著提升，能够更准确地理解和还原用户的创意意图。该模型特别擅长处理复杂的场景描述和艺术风格的精确控制。借助ChatGPT的对话能力，创作者可以反复迭代优化图像，极大降低了AI图像生成的门槛。
