# Microsoft发布Salamander：新一代开源大语言模型

📅 2023-09-18

<!-- 正文开始 -->
Microsoft Research发布Salamander开源大语言模型，这是基于[LLaMA](../../glossary/terms/llama.md) 2训练的新一代代码生成模型。Salamander在保持通用语言能力的同时，专注于提升编程任务处理能力，能够生成高质量的程序代码并提供详细的技术解释。该模型采用了创新的训练方法，在代码补全和代码修复任务上表现优异。Microsoft通过Salamander展示了其在开源AI领域的持续投入。
