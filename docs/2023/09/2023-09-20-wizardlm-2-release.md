# WizardLM 2发布：开源指令微调模型新高度

WizardLM团队发布WizardLM 2系列模型，在开源指令微调领域树立了新的性能标杆。WizardLM 2采用创新的Evol-Instruct技术自动生成复杂的指令数据，显著提升了模型处理高难度任务的能力。该系列包含多个规模的版本，其中WizardLM 2-70B在复杂推理和专业知识问答方面表现出色。WizardLM 2的开源发布延续了团队推动开源大模型发展的理念，为开发者提供了高质量的指令遵循模型选择。
