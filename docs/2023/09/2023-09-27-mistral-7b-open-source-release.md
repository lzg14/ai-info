# Mistral AI 发布 Mistral 7B 开源模型：73 亿参数性能超越 Llama 2 13B

2023年9月底，法国人工智能初创公司 Mistral AI 以 Apache 2.0 开源协议正式发布了 Mistral 7B 语言模型。这款模型仅有 73 亿参数，但在所有基准测试中的表现都优于规模更大的 Llama 2 13B 模型，甚至在部分任务上可以与 [GPT-3.5](../../../glossary/terms/gpt.md) 竞争。[Mistral](../../../glossary/terms/mistral-ai.md) 7B 的发布引起了业界广泛关注，被认为是“欧洲 OpenAI”在开源大模型领域的重要突破。该模型支持处理 8000 个 token 的上下文长度，具备优秀的代码生成能力和自然语言处理能力。Mistral AI 提供了多种下载方式，包括 13.4GB 的 torrent 文件下载，同时在 GitHub 和 Hugging Face 平台上开放了模型仓库。由于采用 Apache 2.0 许可证，Mistral 7B 可以免费商用，为开发者和企业提供了高性能、低成本的选择。
