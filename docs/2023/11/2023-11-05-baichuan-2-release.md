# 百川智能发布Baichuan 2：国产开源大模型新成员

📅 2023-11-05

<!-- 正文开始 -->
百川智能发布Baichuan 2开源大模型，继续深耕中文大模型领域。Baichuan 2在上一代基础上大幅提升了各项能力，尤其在长文本处理和复杂对话方面表现优异。该模型采用完全开源策略，降低了商业应用门槛。百川智能还提供了从模型训练到部署的完整工具链，方便开发者快速基于Baichuan 2构建应用。Baichuan 2的发布进一步壮大了国产开源大模型的力量。
