# OpenAI DevDay：GPTs 和 Assistants API 开启 AI 开发新时代

📅 2023-11-06

<!-- 正文开始 -->
## ️ AI 的"开发者革命"

11月6日，OpenAI 在旧金山举行首届 DevDay 开发者大会，发布了多项重磅产品：

  * **GPTs** ：任何用户都可以无需编程，创建自定义的 [ChatGPT](../../glossary/terms/chatgpt.md) 助手（相当于零代码 Build Your Own AI）
  * **Assistants API** ：帮助开发者更方便地在自己的应用中构建 AI Agent
  * **[GPT-4](../../glossary/terms/gpt.md) Turbo with Vision**：视觉理解能力进入 API



GPTs 的发布被比作"AI 的 App Store 时刻"——用户可以通过对话配置一个专属的 AI 助手，上传知识库、定义行为规则，并将其发布到 GPT Store 供其他人使用。这是 AI 能力首次以"平台化"方式向大众开放。

## 生态雏形

GPT Store 上线后迅速涌现了数千个各类 GPT，涵盖编程助手、写作教练、法律顾问、数学老师等垂直场景，形成了 AI 原生应用的早期生态。
