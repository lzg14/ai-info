# OpenAI首届开发者大会：GPT-4 Turbo与Assistants API发布

📅 2023-11-06

<!-- 正文开始 -->
OpenAI在旧金山举办首届开发者大会，发布了一系列重要更新。除GPT-4 Turbo外，OpenAI还推出了Assistants API，帮助开发者更便捷地构建AI应用。Assistants API提供了代码解释器、检索工具等内置功能，简化了复杂AI应用的开发流程。大会还公布了[ChatGPT](../../glossary/terms/chatgpt.md)即将集成第三方工具等重大消息。首届开发者大会的盛况展示了生成式AI应用的爆发式发展趋势。
