# Mistral Large发布：欧洲大模型新高度

## 🇪🇺 欧洲大模型新高度

1月31日，法国 Mistral AI 发布 Mistral Large，在多项国际基准测试中达到 GPT-4 级别的表现，但价格仅为后者的五分之一。Mistral Large 通过 Azure 和自营平台提供 API 服务，正式进入全球大模型商业竞争。


Mistral Large 的低价策略被视为大模型价格战的提前预演——开源社区的竞争压力迫使闭源模型不得不持续降价以维持市场份额。
