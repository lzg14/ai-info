# Anthropic 扩大 API 开放：Claude 能力全面向开发者释放

## 🔓 Claude API 生态扩展

2月，Anthropic 宣布扩大 Claude API 的开放范围，新增 [Function Calling](../../../glossary/terms/function-calling.md)、批量处理、更长上下文等能力。这使得开发者可以在更多场景中构建 [Claude](../../../glossary/terms/claude.md) 驱动的应用，Claude 从"安全对话 AI"向"全能开发平台"转型。

## 💼 企业采用加速

API 能力的扩展带动 Claude 在 B 端市场的快速渗透，尤其在法律、金融、医疗等对内容准确性要求极高的领域，Claude 凭借其"克制"的内容策略获得企业客户青睐。
