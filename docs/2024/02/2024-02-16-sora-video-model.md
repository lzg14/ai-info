# OpenAI Sora发布：文生视频模型引发全球关注

2024年2月16日，OpenAI正式发布首个文本生成视频模型Sora，这是春节期间最重磅的AI新闻，引发了全球科技界的广泛讨论。Sora能够根据用户输入的文本指令或静态图像，生成长达60秒的视频，包含复杂场景、生动角色表情和多角度镜头切换，且故事逻辑性和连贯性极佳。

Sora的技术架构融合了扩散模型和[Transformer](../../../glossary/terms/transformer.md)架构，能够创建多个镜头和角度切换的高清视频内容，支持宽屏、竖屏和方形等多种画面比例。OpenAI并未将Sora单纯视为视频模型，而是将其定位为"世界模拟器"，目标是教AI理解和模拟运动中的物理世界，帮助解决需要现实世界互动的问题。

Sora发布后，在社交媒体引发了关于AGI（通用人工智能）是否提前到来的热烈讨论。业界普遍认为Sora代表了视频生成技术的重大突破，对影视制作、广告营销和教育等多个行业具有颠覆性影响。同时，也引发了关于深度伪造视频可能被滥用的担忧。

Sora的正式发布（公开版本Sora Turbo）是在2024年12月10日，距离2月的首次预览已有十个月。在这十个月中，AI视频生成领域经历了快速发展，快手可灵AI、Vidu等竞品相继面世。Sora的发布开启了AI视频生成的新纪元，推动了内容创作效率的质的飞跃，也为创意产业带来了全新的可能性。
