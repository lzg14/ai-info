# Pika 发布 Lip Sync 功能：AI视频实现音唇同步

2024年2月28日，AI视频生成初创公司Pika宣布推出Lip Sync（唇形同步）功能，用户可为AI生成的视频角色添加语音对白，并实现精准的嘴唇动画与音频同步。该功能由音频生成公司ElevenLabs提供技术支持，支持文本转语音和自定义上传音轨两种模式。Pika成立于2023年11月，由斯坦福大学前AI博士生郭文景和孟辰霖联合创办，2023年10月已完成5500万美元A轮融资。Lip Sync功能的加入使Pika从纯视觉生成工具升级为可输出完整声画内容的创作平台，标志AI视频技术在视听一致性方面取得实质突破。
