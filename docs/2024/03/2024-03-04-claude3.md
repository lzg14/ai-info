# Anthropic 发布 3 系列：Opus 全面超越 GPT-4

## 🏆 Claude 3 刷新 SOTA

3月4日，Anthropic 发布 Claude 3 模型系列，包含三个版本：Haiku（轻量）、Sonnet（均衡）、Opus（旗舰）。其中 Claude 3 Opus 在 [MMLU](../../../glossary/terms/massive-multitask-language-understanding.md)、GPQA Diamond 等多项基准测试中**全面超越 [GPT](../../../glossary/terms/gpt.md)-4**，标志着闭源大模型的竞争格局被彻底打破。

## 📊 各版本定位

- **Claude 3 Haiku**：极速、省钱，适合简单任务
- **Claude 3 Sonnet**：均衡性能，适合大多数场景
- **Claude 3 Opus**：最强性能，适合复杂推理和专业任务


Claude 3 Opus 的发布被业界称为"GPT-4 垄断的终结"，Anthropic 估值随之突破 150 亿美元。同时，Claude 3 Sonnet 的高性价比策略也对 GPT-4 的市场份额形成显著冲击。
