# AI深度伪造诈骗全球蔓延：2024成"反深伪"元年

📅 2024-03-15

<!-- 正文开始 -->
2024年，AI深度伪造（Deepfake）技术引发的安全危机在全球范围内急剧升级。从香港某跨国公司AI换脸诈骗案，到美国政治人物伪造视频，再到欧盟紧急推进《AI法案》立法，深度伪造已从技术问题演变为社会治理难题。

仅2024年第一季度，全球报告的AI语音克隆诈骗案件同比增长超过300%，平均单笔损失金额超过10万美元。犯罪分子利用生成式AI在几分钟内克隆目标人物的声音和面容，通过视频通话实施冒充诈骗。香港某跨国公司职员因此损失2500万美元，成为当年最严重的AI诈骗案。

面对失控的深度伪造趋势，全球科技巨头联手反击。微软、Adobe、Meta联合发起"内容真实性倡议"（C2PA），要求AI生成内容强制嵌入加密水印和出处凭证。Google推出"关于此图片"功能，借助AI检测帮助用户判断图片是否由AI生成。中国监管机构则发布《互联网信息服务深度合成管理规定》，明确AI生成内容必须打标，不得用于诈骗。

2024年被称为"反深伪元年"——技术攻防战与监管竞赛同步开启，能否在AI能力爆发与滥用风险间找到平衡，将成为未来数年各方共同面对的核心议题。
