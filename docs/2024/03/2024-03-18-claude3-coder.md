# 3 编程能力实测：Code Agent 时代开启

📅 2024-03-18

<!-- 正文开始 -->
## Claude 3 编程评测

3月，多个独立评测显示 Claude 3 Opus 和 Sonnet 在编程任务上表现优异，尤其在代码补全、Bug 修复、架构设计等任务中展现出超越 [GPT-4](../../glossary/terms/gpt.md) 的稳定性。Claude 3 的编程能力催生了 Cursor、Windsurf 等新一代 AI 编程工具的崛起。

Claude 3 的编程能力被 Cursor 迅速集成，其基于 Claude 3 Sonnet 的"Composer"模式让 AI 编程从"辅助补全"升级为"端到端代码生成"，重新定义了 AI 编程工具的标准。
