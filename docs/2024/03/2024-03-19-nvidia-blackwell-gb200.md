# 英伟达发布Blackwell GB200架构GPU AI算力大幅提升

2024年3月，英伟达在GTC大会上正式发布Blackwell架构新一代GPU芯片GB200，标志着AI算力迈入新台阶。相比上一代Hopper架构，Blackwell在AI训练和推理性能上提升数倍，能效比显著优化。GB200采用全新架构设计，支持更强的张量核心和更大的显存带宽，专为大规模语言模型训练和部署打造。此次发布直接推动全球AI军备竞赛进入新阶段，OpenAI、Google、Meta等科技巨头纷纷加速采购计划。Blackwell架构的发布也被视为英伟达巩固其在AI芯片领域霸主地位的关键一步，AMD和英特尔面临更大竞争压力。
