# 1.5 API 正式开放：100 万 token 走向开发者

📅 2024-03-25

<!-- 正文开始 -->
## 长上下文 API 开放

3月25日，谷歌正式向开发者开放 Gemini 1.5 API，100 万 token 上下文窗口正式可用。开发者可通过 Google AI Studio 和 Vertex AI 调用这一能力，构建能够处理超长文档、视频分析、多模态理解的应用。

## 颠覆性场景

100 万 token 上下文催生了大量此前不可能实现的应用：

  * 整本图书的 AI 摘要和问答
  * 数小时视频的内容理解
  * 完整代码仓库的分析和重构
