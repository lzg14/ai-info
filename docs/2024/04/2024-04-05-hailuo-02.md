# MiniMax 发布 Hailuo-02：国产视频生成再突破

## 🎬 国产视频生成

4月5日，MiniMax 发布 Hailuo-02 视频生成模型，在视频生成时长、画质、连贯性等方面较前代有显著提升。MiniMax 作为国内最早布局视频生成的大模型公司之一，Hailuo 系列是其核心产品。


Hailuo-02 在动作连贯性和镜头语言方面表现突出，定位"电影感"视频生成，与国内字节即梦、快手可灵等产品形成竞争态势。
