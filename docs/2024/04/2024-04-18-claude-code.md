# Anthropic 发布  Code：Anthropic 正式入局 AI 编程

📅 2024-04-18

<!-- 正文开始 -->
## Anthropic 的编程工具

4月，Anthropic 正式发布 Claude Code，这是其首个面向开发者的 [Agent](../../glossary/terms/agent-ai-agent.md) 级产品。Claude Code 允许开发者通过命令行与 Claude 协作，自动执行代码补全、Bug 修复、测试编写等任务。

Claude Code 的发布标志着 AI 编程工具正式进入"三足鼎立"时代：GitHub Copilot（微软/OpenAI）、Claude Code（Anthropic）、Cursor（独立+Anthropic），竞争激烈程度前所未有。
