# Vidu视频大模型发布：中国首个对标Sora的长时长高一致性视频生成模型

2024年4月27日，在中关村论坛未来人工智能先锋论坛上，清华大学与北京生数科技联合研发的中国首个长时长、高一致性、高动态性视频大模型Vidu正式发布。Vidu能够根据文本描述直接生成长达16秒、分辨率高达1080P的高清视频，成为OpenAI Sora的有力中国竞争者。

Vidu采用原创的Diffusion与[Transformer](../../../glossary/terms/transformer.md)融合架构U-ViT，支持根据用户文字描述生成视频，不仅能够模拟真实物理世界，还拥有丰富的想象力，具备多镜头生成和时空一致性高等特点。与其他AI视频工具相比，Vidu在角色一致性、动作流畅度和画面质量方面展现了竞争力。

Vidu的发展体现了中国AI视频生成技术的快速进步。到2024年8月，用户反馈仅需不到30秒即可生成一个4秒的视频片段。2025年9月发布的Vidu Q2更进一步，实现从"视频生成"到"演技生成"的跨越，打破了AI生成中表情不自然、动作飘忽不定的行业难题，标志着AI视频生成技术正式从追求"形似"进入追求"神似"的新纪元。

Vidu的发布对中国AI产业具有多重意义。首先，它填补了中国在长时长视频生成领域的空白，与Sora、可灵AI等形成三足鼎立的全球格局。其次，清华大学与产业界的深度合作模式，为中国AI科研成果转化提供了范例。第三，Vidu所展现的技术能力表明，中国在多模态AI领域正在从跟随者转变为创新者的角色。
