# OpenAI 年化收入突破 20 亿美元：大模型商业化里程碑

## 💰 AI 商业化里程碑

4月，多家媒体报道 OpenAI 年化收入已突破 20 亿美元，主要来源为 [ChatGPT](../../../glossary/terms/chatgpt.md) Plus 订阅、API 调用和 Azure 分成。这一数字意味着 OpenAI 成为有史以来商业化速度最快的软件公司之一。

## 📊 收入结构

- Chat[GPT](../../../glossary/terms/gpt.md) Plus 订阅：约 $3.4 亿/年
- API 收入：持续高速增长
- Azure OpenAI 服务分成：约 $2 亿/年
