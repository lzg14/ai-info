# 3.5 即将发布：Anthropic 的反击

📅 2024-05-03

<!-- 正文开始 -->
## 新版本预告

5月初，Anthropic CEO Dario Amodei 在访谈中透露 Claude 3.5 即将发布，将在编程能力、推理速度和长文档处理方面实现重大升级。同时 Anthropic 宣布获得新一笔融资，估值突破 200 亿美元。

Claude 3.5 的消息正值 [GPT-4](../../glossary/terms/gpt.md) 已发布一年多，业界普遍认为 OpenAI 正在酝酿 [GPT](../../glossary/terms/gpt.md)-5 或 GPT-4.5 的发布。大模型市场竞争进入最激烈阶段。
