# DeepSeek V2发布：国产MoE模型性能比肩GPT-4、价格仅百分之一

2024年5月7日，深度求索（DeepSeek）发布全新第二代MoE大模型DeepSeek V2，以极低的API价格和逼近GPT-4的性能表现引发行业关注。DeepSeek V2在评测中得分超过阿里云Qwen2.5-72B和Meta的Llama-3.1-405B，与GPT-4o及[Claude](../../../glossary/terms/claude.md)-3.5-Sonnet不相伯仲，尤其在数学领域大幅领先所有开源闭源模型。

DeepSeek V2的核心技术创新在于其MoE（混合专家）架构。幻方量化作为国内顶级量化私募背景的技术公司，通过自研MoE架构实现了模型性能的跨越式提升。训练计算量显著降低的同时，推理能力表现高效，展现了中国AI研究机构在模型架构创新方面的实力。

价格是DeepSeek V2最引人注目的亮点之一。API价格降至约[GPT-4](../../../glossary/terms/gpt.md) Turbo的百分之一，直接拉开了大模型价格战的序幕。这一价格策略对AI应用层的快速渗透形成了强有力推动——当AI调用成本降低到几乎可以忽略不计时，各类AI应用的经济可行性将大幅提升。

DeepSeek V2的发布标志着中国开源大模型进入了一个新的发展阶段。在性能上已经能够比肩国际顶尖闭源模型，同时保持了开源模型的透明性和可获取性。这种"高性能+低价格"的组合拳，加速了AI技术的民主化进程，使得更多开发者和中小企业能够参与到AI应用的创新浪潮中。
