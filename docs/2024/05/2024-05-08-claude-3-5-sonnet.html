Anthropic 发布 3.5 Sonnet：编程能力超越 GPT-4o

入库 2024-05-08

编程新王

5月8日，Anthropic 发布 Claude 3.5 Sonnet，这是 Claude 3 系列的第三款重要产品。在编程基准测试中，Claude 3.5 Sonnet 的表现显著超越 GPT-4o 和 Gemini 1.5 Pro，尤其在代码补全、Bug 修复和大型代码库理解方面优势明显。

Claude 3.5 Sonnet 的 Agent 能力（使用工具、规划多步任务）较前代大幅提升，被视为 Claude Code 和 Cursor 等 AI 编程工具的重要技术底座。
