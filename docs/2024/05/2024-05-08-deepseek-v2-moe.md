# DeepSeek V2 发布：MoE架构引爆全球大模型价格战

2024年5月，幻方量化旗下深度求索（DeepSeek）发布DeepSeek V2，这是中国AI大模型领域首次在技术架构和商业定价上同时对全球头部玩家形成实质性冲击。DeepSeek V2采用MoE（[Mixture of Experts](../../../glossary/terms/mixture-of-experts.md)，混合专家）架构，总参数2360亿，但每次推理仅激活约210亿参数，实现了性能与成本的最优平衡。

DeepSeek V2最震惊业界的并非技术本身，而是其API定价——每百万Tokens输入仅需1元人民币，输出2元，约为GPT-4o的百分之一。这一价格直接引发全球大模型API价格战，Google、AWS、阿里云等厂商纷纷下调定价，OpenAI也在压力下推出更低价的GPT-4o mini。

在性能方面，DeepSeek V2在MMLU、[HumanEval](../../../glossary/terms/humaneval.md)等基准测试中逼近GPT-4 Turbo水平，尤其在代码生成和数学推理任务上表现突出。[DeepSeek](../../../glossary/terms/deepseek.md)选择MIT协议开源，引爆了开源社区的热情，开发者首次可以在极低成本下调用接近[GPT-4](../../../glossary/terms/gpt.md)水平的模型。

DeepSeek V2的意义远超产品本身——它证明了中国AI公司不仅能跟进国际前沿，更能在架构创新和成本控制上实现弯道超车。这场价格战加速了AI能力的普惠化，让更多中小企业和开发者能够使用世界顶级AI能力。
