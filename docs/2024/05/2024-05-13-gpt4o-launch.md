# OpenAI 发布 GPT-4o：免费开放多模态能力

📅 2024-05-13

<!-- 正文开始 -->
## "Omni"来了

5月13日，OpenAI 发布 GPT-4o（"o"代表 Omni），这是一个原生多模态模型，能够同时处理和生成文本、音频、图像。GPT-4o 的核心突破在于**实时语音对话** ——响应延迟接近人类自然对话，可以随时打断、切换话题，且能理解语气和情绪。

## 定价策略

GPT-4o API 价格大幅下降（是 GPT-4 Turbo 的一半），且 [ChatGPT](../../glossary/terms/chatgpt.md) 免费用户也能使用 [GPT-4](../../glossary/terms/gpt.md)o 的文本和多模态能力，大幅扩大了用户覆盖面。
