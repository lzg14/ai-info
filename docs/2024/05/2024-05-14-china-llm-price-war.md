# 中国大模型价格战：DeepSeek V2引领API价格进入"分"时代

📅 2024-05-14

<!-- 正文开始 -->
2024年5月，DeepSeek V2的发布引爆了中国大模型市场价格战。DeepSeek V2的API价格仅为[GPT-4](../../glossary/terms/gpt.md) Turbo的约百分之一，这一"价格屠夫"策略直接拉低了行业整体定价水平。阿里云、百度、智谱AI等厂商纷纷跟进降价，推动中国AI应用开发进入新时代。

DeepSeek V2的定价策略基于三个因素：MoE架构带来的算力效率提升、自研技术降低的训练成本、以及通过低价扩大市场占有率的战略考量。银河计算机点评报告指出，这一价格策略将利好AI应用层的快速渗透——当AI调用成本降低到以"分"计算时，各类AI应用的经济可行性将大幅提升。

价格战的背后是算力成本持续下降和技术效率不断提升。训练一个高性能大模型的算力需求虽然在绝对值上仍在增长，但相对性能的"性价比"正在指数级提升。这种效率提升最终传导至API定价，使AI能力从"高价商品"变为"平价服务"。

从产业影响看，大模型价格战的赢家将是应用层开发者。低成本意味着更多的实验和创新成为可能。2024年下半年，基于大模型的AI应用数量呈现爆发式增长，包括AI客服、AI写作、AI代码生成等场景快速普及。价格战正在重塑AI行业的价值分布——基础模型利润压缩，应用层创新获益。
