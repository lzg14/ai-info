# 谷歌 I/O 2024：AI 全面接管，从搜索到硬件

📅 2024-05-20

<!-- 正文开始 -->
## ️ 谷歌的 AI 反击

5月20日，谷歌 I/O 大会召开，全场无硬件，全是 AI：

  * **Project Astra** ：AI 助手实时理解摄像头画面，成为真正的"AI 眼睛"
  * **Veo 视频生成** ：对标 Sora，生成 60 秒高清视频
  * **Imagen 3** ：最新图像生成模型，质量超越 DALL-E 3
  * **[Gemini](../../glossary/terms/gemma.md) 1.5 Flash**：更便宜、更快的 API 版本
  * **Gemma 2** ：开源模型升级，27B 参数性能对标 [LLaMA](../../glossary/terms/llama.md) 3 70B



谷歌宣布将 Gemini 全面整合进搜索、广告、Android 等核心产品线，AI First 战略进入全面执行阶段。
