# OpenAI CTO 米拉·穆拉蒂确认离职

## 😢 高管动荡

6月，OpenAI CTO 米拉·穆拉蒂（Mira Murati）确认离职，成为继 2023 年宫变后又一重大高管变动。穆拉蒂被视为 [GPT-4](../../../glossary/terms/gpt.md) 和多项核心技术的重要推手，她的离开引发业界对 OpenAI 内部稳定性的大量猜测。

## 📉 股价与估值影响

虽然 OpenAI 随后获得新融资，但高管连续离职让市场对其治理结构和管理持续性的担忧上升。Anthropic、谷歌等竞争对手趁机加大人才争夺力度。
