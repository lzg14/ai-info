# 通义千问Qwen2发布：全球性能最强的开源模型

2024年6月7日，阿里云通义千问发布第二代开源模型系列Qwen2，首波开源5款模型（0.5B、1.5B、7B、72B、MoE），在同尺寸模型的测评中获得超越所有开源模型的成绩。Qwen2-72B发布后两小时即冲上Hugging Face开源大模型榜单第一，超越[LLaMA](../../../glossary/terms/llama.md) 3-70B。

Qwen2的核心技术升级包括：基于多语言优化架构，新增27种语言支持；显著提升代码与数学推理能力；最高支持128K上下文长度（Qwen2-72B-Instruct）；采用分组查询[注意力机制](../../../glossary/terms/attention-mechanism.md)，在保持性能的同时降低显存消耗。6月20日，斯坦福大学HELM [MMLU](../../../glossary/terms/massive-multitask-language-understanding.md)榜单显示Qwen2-72B成为排名最高的开源模型。

9月19日云栖大会上，阿里云发布Qwen2.5，旗舰模型Qwen2.5-72B性能超越Llama 405B，再登全球开源大模型王座。Qwen2.5涵盖大语言模型、多模态模型、数学模型和代码模型，总计上架100多个模型。此外还开源了Qwen2-VL视觉语言模型和Qwen2-Math数学模型，在各自领域均达到国际领先水平。

Qwen2的成功标志着中国开源大模型进入从"追赶"到"引领"的新阶段。阿里云的密集开源策略（2023年8月至今已开源几十款模型，总下载量突破1600万次）正在重塑全球开源大模型格局。从AI行业影响角度看，Qwen2证明了开源模型在性能上已经足以与闭源模型抗衡，为开发者提供了更多高质量、低成本的选择。
