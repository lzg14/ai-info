# Meta 发布 LLaMA 3.1 405B：开源模型进入" 级别"

📅 2024-06-17

<!-- 正文开始 -->
## 开源之王

6月17日，Meta 发布 LLaMA 3.1 系列，其中 4050 亿参数的 LLaMA 3.1 405B 在多项基准测试中达到 GPT-4 级别。这是首次有开源模型在性能上真正对标闭源旗舰，且完全免费可商用。

## 开源生态

LLaMA 3.1 405B 的发布引爆了开源社区，在 Hugging Face 下载量迅速突破千万次。开发者可以在本地运行"GPT-4 级"模型，推动了 AI 普惠化和企业本地化部署的浪潮。
