# OpenAI 发布 GPT-4o mini：最小最便宜的 GPT-4 级模型

📅 2024-06-20

<!-- 正文开始 -->
6月20日，OpenAI 发布 GPT-4o mini，这是 GPT-4 级别的最便宜、最轻量版本。GPT-4o mini 的 API 价格约为每百万 token $0.15（输入），比 [GPT-3.5](../../glossary/terms/gpt.md) Turbo 还便宜，标志着大模型正式进入"分币级"定价时代。

## 端侧部署

[GPT-4](../../glossary/terms/gpt.md)o mini 的轻量化特性使其适合在移动端和边缘设备部署，推动了端侧 AI 的发展。
