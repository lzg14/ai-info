# Claude 3.5 Sonnet发布：编码能力超越GPT-4o

📅 2024-06-21

<!-- 正文开始 -->
2024年6月21日，Anthropic正式发布Claude 3.5 Sonnet，这是Claude 3.5系列的首款模型，在各种评估中均优于竞争对手和Claude 3 Opus，同时速度和成本与中端型号Claude 3 Sonnet相当。Claude 3.5 Sonnet处理输入速度是Opus的两倍，在编码测试上能够修复64%的代码，而Opus只有38%。

Claude 3.5 Sonnet的核心优势在于其性价比和技术能力的完美平衡。价格方面，输入为3美元/百万tokens，输出为15美元/百万tokens，支持200K上下文窗口。性能方面，在编码任务、视觉处理和复杂推理等多个维度均展现了领先的能力。该模型现已上架Claude.ai、Claude iOS应用以及Amazon Bedrock和Google Cloud Vertex AI。

编码能力的显著提升是Claude 3.5 Sonnet最受关注的技术亮点。在[SWE-bench](../../glossary/terms/swe-bench.md)验证测试中，[Claude](../../glossary/terms/claude.md) 3.5 Sonnet能够解决64%的代码问题，这一数字远超之前的版本和大多数竞争对手。实际测试中，用户反馈该模型在代码生成、调试和优化方面的表现"令人惊艳"，尤其是在理解和解释复杂代码库方面展现了出色的能力。

Claude 3.5 Sonnet的发布对AI编程助手市场产生了深远影响。它不仅为开发者提供了一个高效、低成本的编码工具，也加速了AI编程辅助功能的普及。对Anthropic而言，Claude 3.5 Sonnet是其商业化道路上的重要里程碑，通过平衡性能与成本，成功吸引了更广泛的企业用户群体。
