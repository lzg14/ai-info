# Google发布Gemma 2开源轻量级模型

📅 2024-06-28

<!-- 正文开始 -->
2024年6月27日，Google DeepMind在I/O Connect大会上正式发布Gemma 2，这是Gemma系列轻量级开放语言模型的全新升级版本。Gemma 2提供90亿参数（9B）和270亿参数（27B）两种规格，均提供基础预训练和指令微调版本。27B版本经过13万亿Tokens训练，9B版本经过8万亿Tokens训练，数据涵盖网页文本、代码和数学内容。与第一代相比，Gemma 2重新设计了整体架构，在推理效率和安全性上有显著提升。27B版本性能可与体积两倍于它的模型竞争，能够在单个NVIDIA H100 Tensor Core GPU或TPU主机上运行，大幅降低了部署门槛。Gemma 2支持8K Tokens上下文长度，在LMSYS Chatbot Arena竞技场上取得了开源模型第一的成绩。此外，Google还宣布将于未来几个月内发布26亿参数（2.6B）的手机端版本。
