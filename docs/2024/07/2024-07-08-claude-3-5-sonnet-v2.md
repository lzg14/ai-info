# Claude 3.5 Sonnet 升级：opus 支持编程，能力再突破

## 🏆 编程之王

7月8日，Anthropic 发布 Claude 3.5 Sonnet v2 版本，新增对 Claude 3 Opus 的编程增强支持。同时，Claude 3.5 Sonnet 在 [SWE-bench](../../../glossary/terms/swe-bench.md)（软件工程任务）上的得分从 33% 提升至 49%，全面超越 [GPT-4](../../../glossary/terms/gpt.md)o。

## 💻 Claude Code 更新

Claude Code 也同步更新，新增文件编辑、多步骤任务规划等能力，AI 编程工具的"[Agent](../../../glossary/terms/agent-ai-agent.md) 化"趋势加速。
