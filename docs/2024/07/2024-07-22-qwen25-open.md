# 阿里云开源 Qwen2.5：全面对标

## 🇨🇳 国产开源旗舰

7月22日，阿里云开源 Qwen2.5 系列，涵盖 0.5B 到 72B 多个规格，其中 Qwen2.5-72B 在多项基准测试中逼近 GPT-4 水平。Qwen2.5 在中文能力、数学推理、代码生成方面表现尤为突出。

## 🌏 全球开源社区

Qwen2.5 开源后在 Hugging Face 和 GitHub 获得极高关注，中文开源大模型生态由此真正建立，国产 AI 的国际影响力显著提升。
