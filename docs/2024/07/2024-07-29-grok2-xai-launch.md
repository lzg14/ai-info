# xAI 发布 Grok-2：马斯克旗下最强编程与推理模型

7月29日，xAI 正式发布 Grok-2，这是自 xAI 成立以来最重大的模型升级。Grok-2 在编程能力测试（[HumanEval](../../../glossary/terms/humaneval.md)）、数学基准（MATH）和常识推理方面均达到当时领先水平，部分指标逼近 GPT-4o 和 [Claude](../../../glossary/terms/claude.md) 3.5 Sonnet。

Grok-2 继承了 Grok 系列"反政治正确"的差异化定位，坚持不受限制的言论风格，吸引了大量追求自由表达的用户群体。xAI CEO 马斯克表示，Grok 的使命是追求真理最大化，而非追求"安全"的政治正确。

Grok-2 通过 X 平台 Premium+ 订阅和独立 API 两种方式提供服务，商业化路径逐渐清晰。X 平台为 Grok 提供了独特的分发渠道和数据飞轮，使其能够在短时间内积累大量真实用户反馈。随着 Grok-2 的发布，xAI 的估值也快速攀升至 240 亿美元以上，成为 OpenAI 之外最具竞争力的 AI 玩家之一。
