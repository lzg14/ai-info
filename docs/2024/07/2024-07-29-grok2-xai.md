# xAI 发布 Grok-2：最强编程和推理能力

📅 2024-07-29

<!-- 正文开始 -->
## Grok 新王

7月29日，xAI 发布 Grok-2，这是 Grok 系列的重大升级版本。Grok-2 在编程（[HumanEval](../../glossary/terms/humaneval.md)）、数学（MATH）和常识推理方面表现优异，且继续坚持"反政治正确"的差异化定位，吸引了大批追求自由表达的用户。

## 商业化加速

Grok-2 通过 X 平台 Premium+ 订阅和 API 两种方式提供服务，xAI 的商业化路径逐渐清晰。
