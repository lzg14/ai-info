# OpenAI 向企业全面开放 GPT-4o API

## 🏢 企业级能力

8月5日，OpenAI 正式向企业用户开放 GPT-4o API，这是 GPT-4o 能力首次通过 API 方式提供。企业可获得：
- 文本、图像、音频多模态理解
- 实时语音对话能力
- 增强的 [Function Calling](../../../glossary/terms/function-calling.md)
- 128K 上下文窗口

## 💼 定价策略

[GPT-4](../../../glossary/terms/gpt.md)o API 的定价约为 [GPT](../../../glossary/terms/gpt.md)-4 Turbo 的一半，同时面向中小企业推出更低价格的子版本，推动企业 AI 应用的规模化落地。
