# Figure AI发布第二代人形机器人Figure 02

📅 2024-08-06

<!-- 正文开始 -->
2024年8月6日，美国具身智能公司Figure AI发布了第二代人形机器人Figure 02，创始人兼CEO Brett Adcock将其称为"地球上最先进的人工智能硬件产品"。Figure 02在多个维度实现突破：板载计算和AI推理能力相比前代提升3倍，可完全自主执行现实世界任务；配备6个RGB摄像头驱动的AI视觉系统，能够进行常识性视觉推理；通过与OpenAI合作训练的自定义AI模型，实现了车载麦克风和扬声器支持的语音对话功能。硬件方面，Figure 02可抓取25公斤物体，续航时间达5小时，移动速度为1.2米/秒，配备2.25KWh定制电池组，续航比Figure 01提升50%以上。目前Figure 02已在宝马集团斯帕坦堡工厂进行实习测试，主要负责将金属板件插入特定夹具并组装成车身部件。Figure AI成立于2023年，已累计获得近7亿美元融资，投资者包括OpenAI、微软、英伟达等科技巨头。
