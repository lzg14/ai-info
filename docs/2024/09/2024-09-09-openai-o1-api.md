# API 正式开放：推理能力普惠化

## 🔓 开发者可用

9月9日，OpenAI 正式向开发者开放 o1 API，这是 o1-preview 能力的首次大规模商业化。开发者可以通过 API 构建具有复杂推理能力的 AI 应用，覆盖金融分析、科学研究、代码调试等场景。

## 💰 定价与限制

o1 API 价格约为 [GPT-4](../../../glossary/terms/gpt.md)o 的 4-6 倍，且存在每分钟请求次数限制，反映出推理计算的高成本。OpenAI 同时推出 o1-mini，价格更为亲民。
