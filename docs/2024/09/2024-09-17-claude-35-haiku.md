# 3.5 Haiku 发布：极速与低成本的完美结合

📅 2024-09-17

<!-- 正文开始 -->
## 轻量之王

9月17日，Anthropic 发布 Claude 3.5 Haiku，这是 3.5 系列的轻量版本，响应速度比 Sonnet 快 5 倍，价格仅为后者的十分之一。Claude 3.5 Haiku 适合需要快速响应的 C 端产品，如聊天机器人、实时翻译、文档摘要等场景。

尽管主打轻量，Claude 3.5 Haiku 在大多数任务中的表现与 Claude 3 Sonnet 相当，被认为是"性价比最高"的 Claude 模型。
