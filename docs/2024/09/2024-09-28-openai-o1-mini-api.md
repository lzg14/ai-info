# mini API 开放：推理 AI 走向大众

## 💰 低价推理

9月28日，OpenAI 向开发者开放 o1-mini API，价格约为 o1 的十分之一，使得推理 AI 的应用成本大幅降低。o1-mini 在数学和编程任务上表现出色，适合需要复杂推理但不需要广泛知识的场景。

## 📈 应用场景

o1-mini 的低价策略催生了大量教育（AI 数学辅导）、开发（代码调试）、研究（文献分析）等场景的 AI 应用落地。
