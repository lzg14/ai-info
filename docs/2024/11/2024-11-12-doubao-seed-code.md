# 字节发布 Doubao Seed-Code：国产 AI 编程新力量

## 💻 豆包编程

11月12日，字节跳动发布 Doubao Seed-Code，这是字节首款面向编程场景的 AI 模型。Seed-Code 原生支持 256K 长上下文，是首个支持视觉理解的国产编程模型，可无缝兼容 [Claude](../../../glossary/terms/claude.md) Code 的开发者。

## 📊 市场表现

Doubao Seed-Code 在多项编程基准测试中仅次于 Claude 3.5 Sonnet，位居国产编程模型第一，且通过全量透明 Cache 实现了极低的使用成本。
