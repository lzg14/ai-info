# 谷歌发布 Gemini 3 Pro：全面超越 GPT-4

## 🏆 谷歌反击

11月19日，谷歌正式发布 Gemini 3 Pro，这是 Gemini 3 系列的首个旗舰版本，在 MMLU、MATH、[HumanEval](../../../glossary/terms/humaneval.md) 等所有主流基准测试中**全面超越 GPT-4o 和 [Claude](../../../glossary/terms/claude.md) 3.5 Sonnet**，标志着谷歌正式"收复失地"。


[Gemini](../../../glossary/terms/gemma.md) 3 Pro 的发布被视为大模型竞争格局的"拐点"——OpenAI 的领先优势被大幅压缩，Anthropic、谷歌、Meta 形成真正的三足鼎立格局。
