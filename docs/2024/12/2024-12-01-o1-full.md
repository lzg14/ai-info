# 正式版发布：推理能力全面开放

## 🧠 推理旗舰

12月1日，OpenAI 发布 o1 正式版，这是其推理模型 o1 的完整版本。相比 Preview，o1 正式版在准确性、推理速度和成本方面均有所优化，并向 [ChatGPT](../../../glossary/terms/chatgpt.md) Plus 和 API 用户全面开放。

## 📊 性能表现

o1 正式版在国际数学奥林匹克（IMO）测试中达到 87.7% 的准确率，在 GPQA Diamond（研究生水平科学问题）上超越人类专家平均水平。
