# OpenAI 发布 Sora Turbo：订阅用户可用

📅 2024-12-05

<!-- 正文开始 -->
## Sora 加速

12月5日，OpenAI 在"12 Days"活动第三天发布 Sora Turbo，这是 Sora 的高性能版本，面向 [ChatGPT](../../glossary/terms/chatgpt.md) Plus 和 Pro 用户开放。用户可以生成最长 60 秒的视频，支持 1080p 分辨率和多种宽高比。

## 定价

Chat[GPT](../../glossary/terms/gpt.md) Plus 用户每月可生成最多 90 个视频，Pro 用户为 600 个。独立 API 定价为每视频约 $0.05-0.5 不等。
