# OpenAI 发布 o3-mini：低价推理模型

📅 2024-12-12

<!-- 正文开始 -->
## 性价比

12月12日，OpenAI 发布 o3-mini，这是 o3（尚未完全发布）的轻量版本。o3-mini 保持了 o 系列的核心推理能力，但大幅降低了成本，成为需要复杂推理但预算有限的开发者的首选。

## 基准表现

o3-mini 在数学和科学推理任务中表现接近完整 o1，但 API 价格仅为后者的约三分之一。
