# 2024年AI大模型年终总结：竞争格局重塑，Agent时代正式开启

📅 2024-12-28

<!-- 正文开始 -->
## 格局重塑

2024年是大模型竞争格局被彻底重塑的一年：

  * **OpenAI** ：GPT-4o 和 o1 系列守住领先，但份额被蚕食
  * **Anthropic** ：Claude 3.5 Sonnet 成为编程 AI 标准，估值突破 200 亿
  * **谷歌** ：Gemini 2.0 强力反击，多项基准超越 GPT-4
  * **Meta** ：LLaMA 3.1 405B 开源生态繁荣
  * **国产** ：Qwen2.5、Doubao Seed 等快速崛起



2024年被视为"AI Agent 元年"——Claude Code、Cursor Composer、[OpenAI o1](../../glossary/terms/openai-o1.md) 等产品证明了 AI 已经能够自主完成端到端复杂任务，[Agent](../../glossary/terms/agent-ai-agent.md) 正在重塑软件开发的范式。

## 价格战

2024年大模型 API 价格降幅超过 90%，从"每百万 token 数十美元"降至"不到一美元"，大模型正式进入"水电煤"时代。
