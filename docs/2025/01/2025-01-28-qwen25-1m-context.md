# 通义千问 Qwen2.5-1M 发布：100万 token 上下文

## 📜 超长上下文

1月27-29日春节期间，阿里云通义千问发布 Qwen2.5-1M，支持 100 万 token 上下文，同时开源 Qwen2.5-VL 视觉理解模型，在十余项权威评测中夺得视觉理解冠军，全面超越 GPT-4o 与 [Claude](../../../glossary/terms/claude.md)3.5。


截至1月底，通义开源模型的全球下载量已突破 2 亿次，衍生模型超过 10 万个，成为全球最大的开源模型族群之一。
