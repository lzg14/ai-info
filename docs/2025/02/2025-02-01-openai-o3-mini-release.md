# OpenAI o3-mini上线：推理模型首次向免费用户开放

当地时间2025年1月31日，OpenAI的全新推理模型o3-mini在[ChatGPT](../../../glossary/terms/chatgpt.md)和API上线，并首次向免费用户开放。这一举措标志着AI推理能力的普及化进程加速，普通用户也能体验到前沿的链式思考技术。

o3-mini是OpenAI o系列的第三款模型，主打性价比路线。与付费的o1和o3不同，o3-mini在保持强劲推理能力的同时，将成本控制在更可接受的范围内。OpenAI表示，该模型在数学、编程和科学推理任务上表现出色，适合需要深度分析的专业用户。

值得关注的是，o3-mini延续了o系列的"思考链"能力，能够在给出最终答案前进行多步推理。这种能力对于处理复杂问题至关重要，例如数学证明、代码调试和逻辑分析等场景。免费开放的策略预计将吸引更多开发者基于o3-mini构建应用。

然而，o3-mini的发布也引发了一些讨论。部分用户指出，免费版本的o3-mini存在使用限制，例如每小时的请求配额和生成 token 上限。这表明OpenAI仍在探索合理的商业化路径，在扩大用户基础和控制运营成本之间寻求平衡。
