# o mini 更新：轻量模型能力提升

## ⚡ 轻量升级

2月3日，OpenAI 更新 GPT-4o mini，能力小幅提升但价格继续保持极低水平。GPT-4o mini 继续是大模型性价比之王，每百万 token 输入仅 $0.15。
