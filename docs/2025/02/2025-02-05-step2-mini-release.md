# 阶跃星辰发布Step-2mini：轻量级模型保留80%性能

2025年1月20日，上海阶跃星辰智能科技有限公司宣布推出Step系列语言模型的两款新成员——Step-2mini和Step-2文学大师版。这家被称为"AI大模型六小龙"的企业，凭借其行业领先的模型性能，多次在LiveBench等国际权威榜单上位列国产大模型第一。

Step-2mini是一款轻量级的敏捷模型，以仅3%左右的参数量保有了Step-2超过80%的模型性能。这一成就令人印象深刻，意味着开发者可以在更低的计算成本下获得接近旗舰模型的体验。在输入4000 tokens的情况下，Step-2mini的平均首字时延仅为0.17秒，展现出极快的响应能力。

更值得关注的是，Step-2mini采用了阶跃星辰自主研发的新型[注意力机制](../../../glossary/terms/attention-mechanism.md)架构——MFA（多矩阵分解注意力）及其变体MFA-Key-Reuse。相比传统的多头注意力架构，MFA节省了近94%的KV缓存开销，大幅降低了推理成本。

通过阶跃星辰开放平台调用API，输入成本仅1元/百万token，输出成本仅2元/百万token。这一价格策略预计将推动AI应用开发进入新一轮爆发期，中小开发者也能负担得起高性能大模型的调用费用。
