# MCP协议成为AI Agent互联互通标准

2025年2月，Anthropic主导推出的[Model Context Protocol](../../../glossary/terms/model-context-protocol.md)（MCP）成为AI [Agent](../../../glossary/terms/agent-ai-agent.md)领域的重要标准。短短数月内，已有超过200个开源项目和商业产品宣布支持MCP协议，覆盖工具调用、知识库检索、文件系统操作等场景。

MCP的核心价值在于解决了不同AI Agent和工具之间的互操作性问题。开发者只需编写一次适配代码，即可让Agent连接任何支持MCP的服务或工具。这一特性大幅降低了AI Agent的开发成本，加速了生态系统建设。

AWS、Microsoft Azure、Google Cloud等主流云平台已在其AI服务中提供MCP兼容接口。开源社区也涌现了大量MCP服务器实现，覆盖从数据库查询到第三方API调用的各类场景。行业观察家认为，MCP有望成为AI时代的"USB标准"，实现AI能力的即插即用。
