# 字节豆包 2.0 发布：全模态能力增强

## 🏢 豆包升级

2月22日，字节跳动发布豆包大模型 2.0，在多模态理解、语音对话、文生图等方面全面升级。豆包 2.0 继续坚持"免费+增值"的策略，日均 token 调用量持续高速增长。


豆包 2.0 已整合进抖音、剪映、飞书等字节系核心产品。
