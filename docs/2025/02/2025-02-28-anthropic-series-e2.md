# Anthropic 新融资传闻：估值或突破 350 亿

## 💰 估值新高

2月28日，多家媒体报道 Anthropic 正在洽谈新一轮融资，估值可能突破 350 亿美元。Anthropic 凭借 [Claude](../../../glossary/terms/claude.md) 系列的热销，成为 OpenAI 之外最吸金的 AI 独角兽。


融资将主要用于训练更大规模模型、提升 AI 安全研究能力和扩大商业化规模。
