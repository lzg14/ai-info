# Perplexity完成5亿美元融资，估值达90亿美元

AI搜索公司Perplexity在2025年2月宣布完成5亿美元新一轮融资，由SoftBank Vision Fund领投，估值达到90亿美元，成为AI搜索领域首家准独角兽。本轮融资将主要用于扩大算力基础设施、扩充研发团队以及加速全球市场扩张。

Perplexity的核心产品是AI驱动的答案引擎，能够理解用户问题并直接给出结构化答案，而非传统的链接列表。该公司声称其产品月度活跃用户已突破2000万，其中付费用户占比约15%。本轮融资前Perplexity的年收入已超过8000万美元。

Perplexity CEO表示，公司正在开发下一代对话式搜索引擎，将支持更复杂的多轮对话和多模态交互。此轮融资将进一步巩固Perplexity在AI搜索领域的领先地位。
