# GPT-4o 再更新：多模态能力增强

## 🔄 版本增强

3月3日，OpenAI 为 GPT-4o 发布新版本更新，主要提升图像理解、视频分析和语音合成的自然度。更新后的 GPT-4o 在多模态任务上的表现更加稳定。


GPT-4o 的持续更新有效抵御了来自 [Claude](../../../glossary/terms/claude.md) 3.7 和 [Gemini](../../../glossary/terms/gemma.md) 1.5 Pro 的竞争压力。
