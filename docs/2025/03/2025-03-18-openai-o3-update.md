# OpenAI o3 新版本：推理能力再提升

## 🧠 推理增强

3月18日，OpenAI 为 o3 系列发布新版本更新，在 ARC-AGI 基准测试中的得分从 87.5% 提升至 89%，持续逼近人类专家水平。


新版本在推理过程中引入了更强的自我验证机制，事实错误率比 o1 降低约 40%。
