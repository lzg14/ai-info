# Qwen 2.5 Ultra 1M Context Breaks Long Document Processing Records

📅 2025-03-28

<!-- 正文开始 -->
阿里巴巴在2025年3月发布Qwen 2.5 Ultra，这是通义千问系列的旗舰版本，其最大亮点是支持高达100万token的超长上下文窗口，一举超越了此前所有开源和闭源模型，创下新的行业纪录。

100万token的上下文能力意味着Qwen 2.5 Ultra能够一次性处理整本书籍、完整代码库、大型法律文档或数百份企业年报。这种"全记忆"能力为AI应用开辟了全新的可能：企业可以向模型投入一个完整的产品数据库，让AI自主分析和挖掘数据价值；研究者可以让AI阅读数千篇论文后进行综合述评；律师可以让AI分析涉及数万页材料的复杂案件。

Qwen 2.5 Ultra在其他方面的进步同样显著。在[MMLU](../../glossary/terms/massive-multitask-language-understanding.md)、CMMU和Math等基准测试中，Qwen 2.5 Ultra均达到了开源模型的最高水平。其多模态能力也得到全面增强，能够处理高分辨率图像输入，并准确回答涉及图表、图片和复杂视觉场景的问题。

阿里同时宣布Qwen 2.5 Ultra已通过阿里云百炼平台面向全球开发者开放，并提供了针对企业场景的专属部署方案。Qwen系列模型的开放生态也在持续扩大，目前已有超过1000个基于Qwen的开源模型衍生项目，覆盖了从数学推理到代码生成的各个细分领域。
