# Pro 正式发布：最贵最强推理

## 💎 Pro 登场

4月3日，OpenAI 发布 o1 Pro，这是 o1 系列的旗舰版本，通过 Compute-Optimal Scaling 让模型进行更深度推理，在 ARC-AGI 等高难度测试中达到 92% 的得分。

## 💰 定价

o1 Pro API 价格约为 o1 的 10 倍，主要面向金融、医学、法律等专业领域的高精度需求。
