# OpenAI Agents SDK 发布：Agent 开发框架

📅 2025-04-23

<!-- 正文开始 -->
## ️ 开发工具

4月23日，OpenAI 发布 Agents SDK，这是一个用于构建 AI Agent 的开发框架，支持工具调用、任务规划、记忆管理等核心功能。Agents SDK 与 GPT-5 的 Agent 能力深度整合。

OpenAI 通过 Agents SDK 正式进军 AI Agent 开发框架市场，与 [LangChain](../../glossary/terms/langchain.md)、[AutoGen](../../glossary/terms/autogen.md) 形成正面竞争。
