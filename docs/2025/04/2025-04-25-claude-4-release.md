# Claude 4 系列发布：Anthropic 继续深耕 Agent 能力

Anthropic 发布 Claude 4 系列，包括 **Claude Opus 4.5** 和 **Claude Sonnet 4**，继续强化在代码生成和 Agent 任务上的优势。

## 💻 代码与 Agent 双线突破

Claude Opus 4.5 在代码能力上继续称王，在 SWE-bench（软件工程任务）中刷新纪录，能自主完成复杂的代码修改和 debug 任务。其 Agent 能力也显著提升：支持更长的多步骤任务执行，上下文窗口达到 200K tokens，能在一次对话中完成整个开发流程。

## 🎯 差异化定位

与 GPT-4o 的"全能"路线和 Gemini 的"搜索整合"路线不同，Claude 继续深耕"深度推理+代码+企业级应用"路线，牢牢占据高价值 B 端市场。Anthropic 强调 Claude 的" [Constitutional AI](../../../glossary/terms/constitutional-ai.md)"安全训练路线在 4 系列中进一步优化，模型的幻觉率和对齐能力都有提升。

## 📊 市场格局

[Claude](../../../glossary/terms/claude.md) 4 系列发布后，大模型竞争进入"场景深耕"阶段：OpenAI 占据 C 端和通用场景，[Gemini](../../../glossary/terms/gemma.md) 主打搜索+多模态，Claude 守住企业代码和高价值 B 端，三足鼎立格局初现。
