# OpenAI o3/o4-mini发布：首次实现"图像思考"能力

2025年4月16日（美国东部时间），OpenAI正式发布两款全新AI推理模型——o3与o4-mini，被称为"公司迄今最智能、最强大的模型"。这两款模型在推理任务和工具集成上实现了质的飞跃，更标志着AI从"被动应答"向"自主思考"的范式转变。

o3和o4-mini是历史上首次能够"以图思考"的推理模型。用户可以在对话中上传白板草图或PDF中的示意图，模型会在"思考链"阶段对图像进行分析，再给出回答。借助此能力，它们能识别并处理模糊、低质图像，甚至在推理过程中执行图像缩放与旋转等操作。

这两款模型还能自主调用并组合[ChatGPT](../../../glossary/terms/chatgpt.md)内的所有工具，包括网页搜索、Python代码执行、图像处理与图像生成功能。面对复杂问题时，它们会自动调用相关工具，例如先解析用户上传的文件，再通过联网搜索补充信息，最后生成图文并茂的完整解答。

o3作为旗舰模型，在数学、编程、逻辑推理、科学和视觉理解等多项测试中均优于此前型号。o4-mini则在价格、速度与性能三者之间实现了更具竞争力的平衡，满足开发者在应用场景中对成本与效率的考量。目前，这两款模型已向Pro、Plus与Team订阅用户开放。
