# Qwen3发布：阿里开源混合推理模型，性能对标国际顶级

2025年4月29日，阿里巴巴正式发布旗下全新一代开源大语言模型Qwen3系列，标志着其在人工智能基础模型领域迈出关键一步。Qwen3系列覆盖从小型到超大规模的多种模型规格，包括旗舰版Qwen3-235B-A22B和轻量版Qwen3-30B-A3B，并全面开源，支持研究与商用开发。

Qwen3创新性地引入混合思考模式，支持深度推理与快速响应自由切换。用户可以根据任务复杂度自动选择合适的推理模式，简单问题即时响应，复杂问题深度思考。这一设计兼顾了效率与智能，契合实际应用需求。

在编码、数学推理、综合语言理解等多项国际基准测试中，Qwen3取得了与[DeepSeek](../../../glossary/terms/deepseek.md)-R1、Grok-3、 [Gemini](../../../glossary/terms/gemma.md)-2.5-Pro等顶级模型媲美的成绩。旗舰模型Qwen3-235B-A22B在编码、数学、通用能力等基准评估中取得了有竞争力的结果。

Qwen3还具备119种语言和方言的强大多语言处理能力，极大拓展了全球应用场景。该模型已开放下载，广泛适配Hugging Face、ModelScope等平台，并支持本地部署与API接入，助力开发者和企业快速集成先进大模型能力。
