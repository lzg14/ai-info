# DeepSeek R2 发布：编程能力超越 GPT-4o

📅 2025-05-06

<!-- 正文开始 -->
## R2 登场

5月6日，DeepSeek 发布 R2 推理模型，在编程能力和多语言推理方面实现重大突破。DeepSeek R2 的训练成本继续保持极低水平（约 600 万美元），但性能已超越 GPT-4.5 级别。

编程能力（[HumanEval](../../glossary/terms/humaneval.md)++）超越 GPT-4o、多语言推理能力显著增强、继续保持开源策略、推理成本仅为 [Claude](../../glossary/terms/claude.md) 3.5 Sonnet 的 1/10。
