# OpenAI 推出强化微调（RFT）技术：o4-mini 可定制为领域专家

📅 2025-05-09

<!-- 正文开始 -->
2025年5月，OpenAI 宣布为 o4-mini 模型推出强化微调（Reinforcement Fine-Tuning，RFT）功能，开发者仅需几十条数据即可将 o4-mini 微调为特定领域的专家模型。o4-mini 是 OpenAI 于4月发布的一款紧凑型多模态推理模型，支持文本和图像输入，擅长结构化推理和链式思维提示。

RFT 技术的核心突破在于：传统微调需要大量标注数据且容易导致灾难性遗忘，而强化微调通过结合少量示例与强化学习信号，让模型在特定高风险任务上实现专家级表现。OpenAI 宣布 RFT 向开发者开放早期访问，多家早期采用者已展示在医学诊断、金融风险评估等场景的应用潜力。此举被视为 OpenAI 面向企业市场的重要战略——让紧凑型模型通过定制化适配垂直领域，从而与 [GPT](../../glossary/terms/gpt.md)-5 等大模型形成差异化竞争。RFT 的推出标志着"微调民主化"进程加速，未来更多中小企业和垂直行业将能以低成本打造专属 AI 专家。
