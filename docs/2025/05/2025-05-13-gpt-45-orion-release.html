GPT-4.5（Orion）发布：OpenAI 的反击与下一代模型战略

入库 2025-05-13

Orion 终于到来

经过多次预告，OpenAI 正式发布 GPT-4.5（代号 Orion）。作为 GPT-4 的重大升级版本，Orion 在多模态理解、推理速度和对话一致性上都有显著提升，同时 API 价格大幅下调。

核心升级

  • 多模态能力：原生支持音频理解，可以直接进行语音对话而无需中转文字
  • 上下文窗口：扩展至 256K tokens，能一次性处理长文档、代码库分析
  • 推理效率：长思维链（CoT）能力增强，在复杂推理任务上接近 Claude Opus 4.5
  • 情感理解：更好的对话情感识别，可模拟更自然的对话节奏

价格策略

与之前的高价策略不同，OpenAI 这次采取了激进的降价策略：GPT-4.5 API 价格较 GPT-4o 下降约 60%，免费版 ChatGPT 用户可无限制使用 GPT-4.5 进行对话，呼应了 DeepSeek 引发的价格战。

行业影响

GPT-4.5 的发布被视为 OpenAI 对 DeepSeek R1 和 Claude 4 系列强势反击的标志性事件。Sam Altman 在发布会上表示："我们从 DeepSeek 身上学到了很多——开源和性价比的重要性被我们低估了。"
