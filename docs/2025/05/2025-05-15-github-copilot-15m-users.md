# GitHub Copilot用户突破1500万：AI编程进入爆发期

📅 2025-05-15

<!-- 正文开始 -->
根据最新数据显示，GitHub Copilot的用户已经突破1500万，较去年增长了惊人的四倍。这一数据不仅体现了开发者对AI技术的接受程度，也反映了在编程领域中，AI正从简单的工具演变为不可或缺的合作伙伴。

2025年2月8日，GitHub宣布对Copilot进行重磅更新，增加AI [Agent](../../glossary/terms/agent-ai-agent.md)模式，可以自动迭代代码，识别并修复BUG。同时还发布了另一个Agent——Project Padawan的预览版，主要协助开发人员自动执行重复繁琐的开发流程。

Copilot的"Vision"功能让用户可以在聊天界面中上传截图、照片或图表，AI将根据视觉信息生成相应的界面和代码。这一功能使得开发者和非技术用户都能更直观、高效地将视觉想法转化为实际编程成果。

尤其值得注意的是，在VSCode的Agent Mode中，Copilot能够自主迭代代码，识别并修复错误，极大提升了开发效率。微软CEO萨蒂亚·纳德拉将其称为"编程伙伴"，而非简单的编程工具。
