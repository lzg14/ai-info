# OpenAI 发布 GPT-5：全面超越所有前代

📅 2025-05-22

<!-- 正文开始 -->
## GPT-5 正式发布

5月22日，OpenAI 正式发布 GPT-5，这是被描述为"最接近 AGI 的模型"。GPT-5 在复杂推理、自主 [Agent](../../glossary/terms/agent-ai-agent.md)、长时记忆、跨模态理解等方面实现全面突破。

Agent 原生内置工具调用、自主规划能力、长记忆跨会话持续学习、多模态文本图像音频视频代码全面超越。
