# Claude 4发布：Anthropic推出全球最强编程模型

📅 2025-05-23

<!-- 正文开始 -->
2025年5月23日，Anthropic在首届开发者大会"Code with Claude"上正式发布Claude 4系列模型——Claude Opus 4和Claude Sonnet 4。这是该公司历史上最强大的AI模型，在结构化推理、软件工程和自主代理行为等领域实现重大进步。

Anthropic CEO Dario Amodei在大会上表示："我们不再教AI如何回答问题，而是教它们如何解决问题。"这一理念转变标志着Claude 4从"对话辅助"向"自主智能体"的全面转型。Claude Opus 4被官方誉为"全球最强编码模型"，在专业基准测试中取得领先成绩。

Claude 4能够分析数千个数据源，执行长时间运行的任务，编写与人类水平相当的内容，并执行复杂的操作。在测试中，Claude Opus 4可连续稳定工作7小时以上，远超竞争对手。

大会上，Anthropic还宣布了多项工具和API更新，包括支持本地文件记忆功能，开发者可授权模型动态维护"记忆文件"以提升任务连贯性。Claude 4的发布加剧了AI编程助手领域的竞争，直接对标GitHub Copilot和Cursor。
