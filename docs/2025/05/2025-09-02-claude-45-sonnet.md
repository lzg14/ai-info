# Anthropic  4.5 Sonnet 发布：上下文200万，编码能力登顶

9月2日，Anthropic 发布 Claude 4.5 Sonnet，将上下文窗口扩展至突破性的 200 万 token，同时大幅提升编码能力和复杂推理能力。Claude 4.5 Sonnet 在多个基准测试中表现优异，尤其在编码任务上实现登顶，超越 GPT-5 和 [Gemini](../../../glossary/terms/gemma.md) 2.5 Pro。


Claude 4.5 Sonnet 采用新一代[注意力机制](../../../glossary/terms/attention-mechanism.md)优化，在超长上下文中保持一致的推理质量。新增的 "代码执行代理" 能力可自主完成代码调试、重构和测试。上下文压缩技术的突破使长文档处理成本大幅降低，为企业应用提供更经济的选择。

## 🌐 Claude 家族

Claude 4.5 Sonnet 的发布完善了 Claude 家族产品线：Haiku 主打低延迟、Sonnet 平衡性能与成本、Opus 定标旗舰高端市场。Claude AI 助手全面升级支持多模态理解，企业 API 价格下调推动应用普及。
