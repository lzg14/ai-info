# GPT-4o 正式版发布：多模态能力全面开放

## 🎯 正式版上线

6月3日，OpenAI 正式发布 GPT-4o 正式版，这是继 5 月预览版发布后首个稳定的商业版本。GPT-4o 正式版在响应速度、稳定性和 API 可用性方面均有提升，并向 ChatGPT 免费用户开放多模态能力。


GPT-4o 正式版支持：
- 实时语音对话（打断、多轮、情感识别）
- 图像理解和生成
- 视频理解（截图分析）
- 128K 上下文窗口
- [Function Calling](../../../glossary/terms/function-calling.md) 增强
