# Pro 发布：最贵最强的推理模型

📅 2025-06-15

<!-- 正文开始 -->
## Pro 版本

6月15日，OpenAI 发布 o1 Pro，这是 o1 系列的旗舰版本，通过 Compute-Optimal Scaling 技术让模型"思考更长时间"以获得更准确的答案。o1 Pro 主要面向需要最高准确性要求的场景，如医学研究、数学证明、关键代码审计等。

## 高定价

o1 Pro API 定价约为 o1 的 10 倍，主要面向企业级推理需求市场。
