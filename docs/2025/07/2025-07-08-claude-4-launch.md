# Anthropic 发布 Claude 4 Opus：编程能力新王

## 🏆 Claude 4 发布

7月8日，Anthropic 发布 Claude 4 系列，包含 Opus 和 Sonnet 两个版本。Claude 4 Opus 在 [SWE-bench](../../../glossary/terms/swe-bench.md) 编程测试中达到 72% 的得分，大幅刷新 [Claude](../../../glossary/terms/claude.md) 3.7 Sonnet 的记录，稳坐"最强编程 AI"宝座。


Claude 4 在 Agent 架构上全面升级：
- 多步骤任务自主规划
- 代码库深度理解
- 更稳定的工具调用
- 记忆能力增强
