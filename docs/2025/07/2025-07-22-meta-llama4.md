# Meta 发布  4：1000万 token 上下文

## 🦙 LLaMA 4 发布

7月22日，Meta 发布 LLaMA 4 系列，其中旗舰版本支持 1000 万 token 上下文窗口，刷新了业界纪录。LLaMA 4 采用 MoE 架构，在保持高性能的同时大幅降低了推理成本，继续巩固开源大模型生态。


LLaMA 4 的发布对开源社区意义重大：
- 1000 万 token 上下文免费可用
- MoE 架构效率大幅提升
- 支持多语言和代码理解
