# OpenAI 发布 .5：1万亿参数，幻觉率新低

## 🏆 GPT-4.5 登场

7月31日，OpenAI 发布 GPT-4.5，据称参数量达 1 万亿，是 GPT-4 的约 10 倍。GPT-4.5 在保持强大能力的同时，显著降低了幻觉率（事实错误），在长文档理解、复杂推理和专业领域知识方面达到新高度。


GPT-4.5 API 价格较 GPT-4o 有所提升，但仍是 GPT-4 Turbo 的 50% 左右，继续推动大模型商业化。
