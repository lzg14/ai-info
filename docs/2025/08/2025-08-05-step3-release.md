# 阶跃星辰Step 3发布：首个全尺寸原生多模态推理模型

2025年7月25日，阶跃星辰在上海召开"Step 3大模型发布会暨生态联盟成立大会"，发布了首个全尺寸、原生多模态推理模型Step 3。该模型将于7月31日面向全球企业和开发者开源，再次展示了中国AI企业的技术实力。

阶跃星辰CEO姜大昕介绍，Step 3采用MoE架构，总参数量321B（3210亿），激活参数量38B（380亿），却可以在较高推理解码效率下实现关键的成本优化过程。该模型在国产芯片上的推理效率最高可达[DeepSeek](../../../glossary/terms/deepseek.md)-R1的300%，且对所有芯片友好。

Step 3是阶跃星辰首个全尺寸、原生多模态推理模型，拥有强大的视觉感知和复杂推理能力，可准确完成跨领域的复杂知识理解、数学与视觉信息的交叉分析，以及日常生活中的各类视觉分析问题。

会上，阶跃星辰还宣布联合多家国内领先的芯片、平台厂商发起成立"模芯生态创新联盟"，通过推动模型和芯片产业链联合创新，加速大模型应用的落地。这一生态建设策略有望推动国产AI技术的整体进步。
