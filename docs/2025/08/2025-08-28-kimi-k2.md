# 月之暗面 Kimi K2 发布：国产推理新力量

## 🌙 K2 登场

8月28日，月之暗面发布 Kimi K2，这是其旗舰推理模型的重大升级版本。K2 在数学推理、代码生成和逻辑分析方面表现优异，被认为已具备与 [GPT-4](../../../glossary/terms/gpt.md)o 正面对抗的能力。


K2 继续保持 200K token 上下文窗口优势，在长文档处理、代码库分析等场景中具有明显优势。
