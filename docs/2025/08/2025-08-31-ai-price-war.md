# 大模型价格战持续：每百万 token 进入"分"时代

📅 2025-08-31

<!-- 正文开始 -->
## 价格再降

2025年8月，大模型 API 价格继续下降，主流模型每百万 token 输入价格已降至 0.1 美元以下，部分国产模型甚至进入"厘"时代（约 0.001 元/tokens）。

## 竞争格局

价格战的背后是：

  * 算力成本持续下降
  * 模型效率优化（投机解码、量化的进步）
  * 国内大厂争夺市场份额
  * OpenAI、Anthropic 被迫跟进降价
