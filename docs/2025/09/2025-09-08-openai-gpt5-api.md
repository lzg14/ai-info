# GPT-5 API 正式开放：大模型进入新纪元

📅 2025-09-08

<!-- 正文开始 -->
## 开发者可用

9月8日，OpenAI 正式向开发者开放 GPT-5 API，这是 GPT-5 能力首次大规模商业化。开发者可以通过 API 构建基于 GPT-5 的应用，覆盖 Agent 编程、深度研究、多模态理解等场景。

## 定价

GPT-5 API 定价约为 [GPT-4](../../glossary/terms/gpt.md)o 的 3 倍，但考虑到其 [Agent](../../glossary/terms/agent-ai-agent.md) 能力和推理性能的提升，性价比仍然显著高于雇佣人类专家。
