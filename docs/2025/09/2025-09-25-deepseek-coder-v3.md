# DeepSeek Coder V3 发布：国产编程模型新高度

📅 2025-09-25

<!-- 正文开始 -->
## 编程旗舰

9月25日，DeepSeek 发布 Coder V3，这是其编程模型的旗舰版本，在 [SWE-bench](../../glossary/terms/swe-bench.md) 编程测试中得分超越 Claude 4 Sonnet，逼近 Opus 水平。[DeepSeek](../../glossary/terms/deepseek.md) Coder V3 继续保持开源策略，对 Cursor、Windsurf 等 AI 编程工具形成吸引力。

DeepSeek Coder V3 的推理成本仅为 [Claude](../../glossary/terms/claude.md) 3.5 Sonnet Code 的 1/20，对开发者和小型团队极具吸引力。
