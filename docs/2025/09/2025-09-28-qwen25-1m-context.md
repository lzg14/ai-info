# 通义千问 Qwen2.5-1M 发布：100万 token 上下文

📅 2025-09-28

<!-- 正文开始 -->
## 超长上下文

9月28日，阿里云发布 Qwen2.5-1M，这是支持 100 万 token 上下文的版本，专为处理超长文档、视频分析等场景设计。Qwen2.5-1M 在超长上下文理解任务中表现优异，适用于法律文档分析、科研论文处理等场景。

Qwen2.5-1M 的核心版本开源，推动国产大模型在长上下文领域的技术进步。
