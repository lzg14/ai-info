# OpenAI DevDay 2025：GPT-5 Plugins 和 Agents SDK

## 🛠️ 开发者大会

10月27日，OpenAI 举行 DevDay 2025，发布多项重磅开发者工具：
- GPT-5 Plugins 全面开放
- Agents SDK 正式版
- 更强大的 Assistants API
- 新版 Fine-tuning API


OpenAI 通过 Agents SDK 正式进军 AI Agent 开发框架，与 [LangChain](../../../glossary/terms/langchain.md)、[AutoGen](../../../glossary/terms/autogen.md) 等形成正面竞争。
