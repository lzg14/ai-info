# OpenAI o3 Pro 发布：推理能力新巅峰

📅 2025-11-03

<!-- 正文开始 -->
## Pro 推理

11月3日，OpenAI 发布 o3 Pro，这是 o3 系列的旗舰版本，通过 Extended Thinking++ 技术让模型进行更深度、更长时间的推理。o3 Pro 在 ARC-AGI 基准测试中达到 91% 的得分，逼近人类专家水平。

## 定价

o3 Pro API 价格约为 o1 的 20 倍，主要面向对推理准确性有极高要求的金融、医学、法律等专业领域。
