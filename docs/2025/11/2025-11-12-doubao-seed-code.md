# 字节 Doubao Seed-Code 发布：Agentic Coding 杀入

## 💻 编程新王

11月12日，字节跳动发布 Doubao Seed-Code，这是字节首款面向编程场景的 Agent 级模型，原生支持 256K 长上下文，是首个支持视觉理解能力的国产编程模型，兼容 [Claude](../../../glossary/terms/claude.md) Code 的开发者。

## 📊 性能表现

Doubao Seed-Code 在多项主流编程基准测试中仅次于 Claude 3.5 Sonnet，位居国产编程模型第一。
