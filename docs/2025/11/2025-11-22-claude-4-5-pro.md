# Anthropic  4.5 Pro 发布：企业级首选

📅 2025-11-22

<!-- 正文开始 -->
## Pro 版本

11月22日，Anthropic 发布 Claude 4.5 Pro，这是 Claude 4.5 系列的旗舰企业版本，专为大并发、高可靠性要求的企业场景优化。Claude 4.5 Pro 在长文档处理、多文件编程任务中表现稳定。

Claude 4.5 Pro 已成为企业级市场的首选，企业用户数量突破 100 万家。
