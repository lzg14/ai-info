# OpenAI o3 API 正式开放：推理模型普惠化

## 🔓 开发者可用

12月1日，OpenAI 正式向开发者开放 o3 API，这是 o3 推理能力首次大规模商业化。开发者可以构建具有复杂推理能力的 AI 应用，覆盖金融分析、科学研究、代码调试等场景。

## 💰 定价优化

o3 API 价格较 o1 有显著下降，但仍属于高端定价，每百万 token 约 $10-50 不等。
