# OpenAI GPT-5.3-Codex发布编程能力持续突破

OpenAI发布GPT-5.3-Codex，运行速度提升25%，[SWE-bench](../../../glossary/terms/swe-bench.md) Pro得分57%、TerminalBench2.0得分76%，令牌消耗减少50%。该模型具备自主优化调试能力，可生成功能齐全的网站设计，配套推出企业级Frontier平台。
