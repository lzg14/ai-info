# OpenAI GPT-5.4 mini和nano轻量模型发布价格大降

📅 2026-03-05

<!-- 正文开始 -->
OpenAI发布GPT-5.4 mini和nano轻量模型。mini在[SWE-bench](../../glossary/terms/swe-bench.md) Pro编码测试达54.4%（距满血版差3.3%），输入0.75美元/百万token、输出4.5美元（仅为GPT-5.4的1/3），支持40万上下文窗口；nano输入0.2美元/百万token、输出1.25美元，向[ChatGPT](../../glossary/terms/chatgpt.md)免费用户开放。
