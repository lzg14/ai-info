# 国家药监局出台人工智能药品监管专项规划

国家药监局出台人工智能+药品监管专项规划，AI医疗行业迎来政策端利好。联影智能自主研发的元智医疗多模态大模型入选国家人工智能应用中试基地（医疗领域）核心创新成果，支持10余种影像模态、300余项影像处理任务，在复杂病灶识别等关键场景中精准度超95%。
