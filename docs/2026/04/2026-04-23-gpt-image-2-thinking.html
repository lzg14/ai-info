GPT Image 2 最完整解读：第一个会"思考"的图像模型

入库 2026-04-23

多模态

OpenAI 的 ChatGPT Images 2.0 震撼发布，其"思考模式"与多语言支持能力彻底颠覆了图像生成的范式。

三端同时全量上线：ChatGPT、Codex、API。带思考模式（Thinking）的进阶版本，仅 ChatGPT Plus、Pro、Business 用户能用。API 模型名：gpt-image-2，通过 Image API 和 Responses API 都能调用。

价格涨幅显著：high 档方图从 $0.133 涨到 $0.211（+59%）；medium 档从 $0.034 涨到 $0.053（+56%）。

思考模式是最大范式变化——这是 OpenAI 第一个带思考能力的图像模型，做三件事：①联网搜索实时信息 ②一次产出最多8张连贯图 ③自我检查输出质量。核心价值不是"画得更好"，是"替你想清楚"。

中文文字渲染突破：每个汉字都准，包括超小字号。这代国内用户最直接受益的变化。

其他亮点：

  • 多尺寸广告一次生成（Twitter、IG、LinkedIn 同时出）
  • 3:1 超宽到 1:3 超高都能跑
  • API 端 2K 以上分辨率当前是 beta；复杂提示词延迟最高可达 2 分钟
