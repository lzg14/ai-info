# DeepSeek-V4系列密集落地V4-Pro开源V4-Flash仅0.279美元

📅 2026-05-02
📢 来源：AI资讯

4月24日发布的DeepSeek-V4系列进入密集落地阶段：V4-Pro（1.6万亿参数）与V4-Flash（284B参数）双双开源，Flash版本定价仅每百万Token 0.279美元，与[GPT](../../../glossary/terms/gpt.md)-5.5标准版之间的价差高达645倍。DeepSeek以极致性价比继续扮演开源阵营的价格破坏者，推动大模型API价格整体下探。
