## 背景

OpenClaw创始人Peter低调发布了一款全新Computer Use工具——**Peekaboo v3**（中文意为"躲猫猫"）。

这款工具剑指过去Agent类产品一直存在的痛点：只能执行简单流程，无法直接操控桌面。Peekaboo v3让AI Agent不仅能"看"到屏幕，还能真正动手操作鼠标键盘。

社区已有开发者做了简单的"Computer Use"烟雾测试：让Hermes操作计算器、Peekaboo读屏幕结果、Python独立验证答案，一气呵成成功通过。

## 技术能力：从"指手画脚"到"真能干活"

Peekaboo v3的核心升级在于**双重能力**：

### 「看」的能力

- 像素级截图，覆盖窗口、全屏、菜单栏
- 读取macOS上每个UI元素的位置、类型、label等属性

### 「动」的能力

支持完整的Mac操作模拟：

- 点击、输入文字、按快捷键
- 滚动、拖拽
- 切窗口、切桌面（Space）
- 戳Dock、点系统弹窗

### 聪明的工程设计

- **自然语言Agent模式**：指令可以直接用大白话，底层自动解析
- **MCP协议支持**：所有能力打包成MCP Server，可直接接入Cursor、Claude Code、Codex等主流AI编程工具，实现"截图→分析→修改→验证"全自动闭环

## 四种使用方式

| 场景 | 方式 |
|------|------|
| 写脚本自动化 | `brew install steipete/tap/peekaboo` |
| AI编程工具接入 | `npx -y @steipete/peekaboo mcp` |
| 普通Mac用户 | GitHub Releases下载桌面版App |
| Swift开发者 | Swift Package引入作为库 |

对于OpenClaw用户，还可以通过"Skill"一键安装，相当于给OpenClaw装上操作Mac的插件，录屏、辅助功能等权限一次性配置完成。

## 行业背景

Peekaboo v3密集更新的背后，是AI Agent"操控电脑"赛道的激烈竞争：

- Anthropic推出Computer Use
- OpenAI推出Operator
- 各类browser-use工具疯狂涌现

Peter必须保持迭代节奏，一方面避免被后来者追上，另一方面也为自己的Agent工作提供最强的本地验证平台。
