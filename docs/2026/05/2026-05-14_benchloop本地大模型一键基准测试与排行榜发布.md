# BenchLoop：本地大模型一键基准测试与排行榜发布

📢 来源：X：Berry Xia (@berryxia)

🏷️ [ · " · 技 · 巧 · " · ]

<!-- 正文开始 -->

BenchLoop 提供了一套对本地大模型进行基准测试的标准化流程。用户只需拉取模型并运行该工具，即可实时获取模型在质量、速度和可靠性方面的综合评分。平台支持对比不同提示框架（如原生模式与 Hermes 模式）下的性能表现。测试完成后，结果可自动发布至公开排行榜，便于横向比较不同模型的优劣。
