# GitHub Copilot CLI 入门指南：交互模式与非交互模式

📢 来源：GitHub Blog

🏷️ [ · " · 技 · 巧 · " · ]

<!-- 正文开始 -->

GitHub Copilot CLI 提供了交互与非交互两种主要使用模式。交互模式允许用户通过对话式指令逐步构建和调整命令，适合探索性任务。非交互模式则支持直接输入完整指令快速执行，适用于自动化脚本或已知命令。理解这两种模式的区别能帮助开发者更高效地利用该工具，提升命令行工作效率。
