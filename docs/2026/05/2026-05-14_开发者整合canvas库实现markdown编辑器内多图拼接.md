# 开发者整合Canvas库实现Markdown编辑器内多图拼接

📢 来源：X：Vista (@vista8)

🏷️ [ · " · 技 · 巧 · " · ]

<!-- 正文开始 -->

针对教程写作中拼接多张图片需借助Figma等工具过于笨重的问题，开发者通过与AI讨论，获得使用HTML5 Canvas库的解决方案。现已将该功能整合到Markdown编辑器中，用户可直接在编辑器内完成多图拼接，随后将拼合好的图片插入文章或导出。相关代码已开源至Github项目。
