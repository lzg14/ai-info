# Mac远程运行Codex，手机办公两不误

📅 2026-05-18
📢 来源：X：OpenAI Developers (@OpenAIDevs)

🏷️ [ · " · 技 · 巧 · " · ]

<!-- 正文开始 -->

你的Mac可以在你用手机工作时坚守岗位。
在Codex桌面应用中启用远程连接，然后开启"保持Mac唤醒"。
当Mac开机并接通电源时，Codex可以持续运行，而你则通过ChatGPT移动应用工作。
