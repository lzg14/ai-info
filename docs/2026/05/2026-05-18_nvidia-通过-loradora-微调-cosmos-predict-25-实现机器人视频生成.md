# NVIDIA 通过 LoRA/DoRA 微调 Cosmos Predict 2.5 实现机器人视频生成

📅 2026-05-18
📢 来源：Hugging Face：Blog（RSS）

🏷️ [ · " · 技 · 巧 · " · ]

<!-- 正文开始 -->

NVIDIA 在 Hugging Face 发布博客，介绍其视觉生成模型 Cosmos Predict 2.5 的微调方案。该方案采用 LoRA 和 DoRA 两种参数高效微调技术，使模型能够基于文本提示生成高质量的机器人第一视角视频。这降低了在机器人领域定制视频生成模型的门槛，无需从头训练或使用海量数据，即可让模型掌握特定场景和动作的视频合成能力。
