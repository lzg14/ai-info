# 开源微信读书数据可视化工具yao-weread-skill发布

📢 来源：X：Vista (@vista8)

🏷️ [ · " · 技 · 巧 · " · ]

<!-- 正文开始 -->

开发者姚老师开源了微信读书Skill——yao-weread-skill。该工具能将用户的微信读书数据生成本地可视化报告，核心功能包括分析近两年的阅读时长与节律、书架书籍构成、阅读分类与作者偏好，并对笔记和想法进行语义分析。报告最终通过词云、热力图、雷达图等26种图表形式呈现，所有代码已在GitHub公开。
