# 沙钢签约钉钉，让悟空成为每一位“钢铁人”的生产力工具

沙钢签约钉钉，让悟空成为每一位“钢铁人”的生产力工具
实现AI技术从“能力”到“价值”的转化
允中 发自 凹非寺
量子位 | 公众号 QbitAI
5月28日，江苏沙钢钢铁有限公司（以下简称“沙钢”）与钉钉正式签署战略合作协议。双方将围绕全集团协同办公底座建设及AI场景应用落地展开深度合作，重点以钉钉悟空和一系列AI产品为核心引擎，推动AI在钢铁行业的规模化落地，助力沙钢全力打造AI时代的工作方式。沙钢集团常务执行董事、联席总裁陈少慧和钉钉、悟空创始人陈航出席签约仪式。
沙钢创立于1975年，是中国规模最大的民营钢铁企业集团，年产钢规模位居全国前列，连续多年跻身中国企业500强，旗下员工数万人，业务覆盖全球多个国家和地区。近年来，沙钢将数字化、智能化转型列为企业发展的核心战略，持续加大在数字基础设施、智能制造及AI应用方面的投入，致力于打造世界一流的数智化钢铁企业。
本次战略合作的核心，是双方以专属钉钉底座为基础，以悟空AI为智能引擎，围绕钢铁行业的实际业务痛点，共同打造全集团的协同办公平台，并推进落地七大AI创新智能场景，实现AI技术从“能力”到“价值”的转化。
在协同办公底座层面，沙钢将基于专属钉钉数字底座，集成现有OA、HR、财务等核心业务系统，实现统一账号管理、单点登录与数据互通，并配套数据私有化混合存储、安全管控，为企业数字化转型夯实地基。
在AI场景落地层面，沙钢还将全面引入钉钉智能体开发平台，为AI场景的规模化落地夯实扎实根基，并计划未来在全集团推广应用悟空，将其深度融入沙钢日常运营的各个环节，打造AI原生组织，激发组织力与员工个体创造力。例如双方共同打造的“KYT安全隐患自动检查助手”，能利用AI视觉识别技术对生产现场视频图像进行实时采集、审核，自动识别安全隐患，为钢铁生产安全提供智能防护。
此外，双方还将共同推进沙钢AI人才梯队建设，通过系统性AI培训工作坊培养数智化先锋，打造并推广可复用的AI应用场景和标杆数智化应用。
沙钢集团常务执行董事、联席总裁陈少慧表示：“此次与钉钉的战略合作，是沙钢智能化转型进程中的重要里程碑。钉钉在企业协同与AI应用领域的深厚积累，将为沙钢打造世界一流数智化钢铁企业提供强有力的支撑。期待通过钉钉、悟空的深度应用，让AI真正成为每一位沙钢员工的生产力工具，全面提升沙钢的管理效能与运营竞争力。”
钉钉、悟空创始人陈航表示：“钢铁行业是中国制造业的脊梁，也是AI技术规模化落地的重要阵地。与沙钢的合作，是钉钉、悟空在重工业场景深度实践的重要里程碑。我们将把最前沿的AI能力与沙钢的实际业务深度融合，帮助沙钢打造真正可落地、可复用的行业AI标杆，为中国钢铁行业的数智化转型提供示范样本。”
此次战略合作协议的签署，标志着钉钉与中国头部民营钢铁企业在AI应用领域的深度合作正式开启。未来，双方将持续深化以悟空为核心的智能化应用探索，不断拓展AI在钢铁生产、安全管理、供应链协同等更多场景的应用边界，共同为中国制造业的数智化转型树立可借鉴、可推广的行业新标杆。
