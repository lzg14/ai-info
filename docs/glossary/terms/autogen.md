# AutoGen



<!-- 正文开始 -->
**解释：** AutoGen 是微软推出的开源多智能体（Multi-Agent）编程框架，允许开发者构建多个 AI Agent 并让它们相互协作完成复杂任务。比如一个 Agent 负责写代码，另一个 Agent 负责审查代码，第三个 Agent 负责测试——它们可以相互对话、分配任务。

**为什么重要：** AutoGen 是 2025 年 Agent 应用框架爆发的代表，它的出现让多 Agent 系统的构建从研究走向工程化，大大降低了开发门槛。
