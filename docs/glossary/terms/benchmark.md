# Benchmark



<!-- 正文开始 -->
**解释：** Benchmark 是 AI 领域的「考试」——一套标准化的测试题目和评分规则，用来客观衡量不同模型的性能。常见的有 MMLU（选择题）、HumanEval（编程）、GSM8K（数学）等。就像考试成绩能比较学生一样，Benchmark 分数能比较不同大模型的能力高下。

**为什么重要：** 没有 Benchmark 就没法客观评价模型好坏。2024-2026 年各模型在各类 Benchmark 上的刷榜竞争，是观察大模型军备竞赛的重要窗口。
