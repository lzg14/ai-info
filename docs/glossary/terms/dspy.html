术语

DSPy

英文：DSPy (Declarative Self-Improving Language Programs)

解释： DSPy 是斯坦福 2023 年 11 月发布的 LLM 编程框架，核心理念是将 Prompt 工程和训练过程「声明式化」。传统做法是：手动写提示词 → 测试 → 不好就改提示词 → 再测试。DSPy 的做法是：写出高层意图（用哪些模块、干什么），DSPy 自动学习最优的提示词组合和模块连接方式。

为什么重要： DSPy 将 LLM 应用开发从「调参玄学」推向「系统化优化」，是 2024-2026 年 Agent 应用框架的重要方向，对 AutoGen、LangChain 等都有影响。
