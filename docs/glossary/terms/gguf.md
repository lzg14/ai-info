# GGUF



<!-- 正文开始 -->
**解释：** GGUF 是 llama.cpp 项目（由 Georgi Gerganov 开发）推出的大模型量化文件格式，用于存储和快速加载量化后的大模型权重。它将模型的全部信息（权重、配置、元数据）打包成单个文件，支持 INT8、INT4、Q4_K_M 等多种量化精度，让大模型能在 CPU 和低显存 GPU 上运行。

**为什么重要：** GGUF 让「消费级显卡跑大模型」成为可能，是 Ollama 等本地运行工具的底层格式，也是 2024 年「个人本地大模型」浪潮的推动者。
