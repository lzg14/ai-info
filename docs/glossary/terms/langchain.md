# LangChain



<!-- 正文开始 -->
**解释：** LangChain 是一个用于构建 LLM 应用的开源开发框架，提供了提示词管理、链式调用（Chain）、Agent 抽象、记忆（Memory）、工具集成等模块。开发者可以用 LangChain 快速将 RAG、Tool Use、多轮对话等能力拼装成完整的 AI 应用。

**为什么重要：** LangChain 是 2023-2024 年 AI 应用开发领域最热门的框架，虽然后来受到 AutoGen、Agent SDK 等新框架的冲击，但仍然是生态最丰富的 LLM 应用开发工具之一。
