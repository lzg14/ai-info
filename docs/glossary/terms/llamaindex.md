# LlamaIndex



<!-- 正文开始 -->
**解释：** LlamaIndex 是一个专注于知识检索增强（RAG）的 LLM 应用开发框架，提供数据连接器、索引结构（List Index、Vector Store Index、Tree Index 等）、查询接口等模块。与 LangChain 相比，LlamaIndex 更专注于知识检索场景，是构建私有知识库问答系统的首选框架。

**为什么重要：** LlamaIndex 是 RAG 场景最流行的框架，2023-2026 年几乎所有企业知识库问答项目都有 LlamaIndex 的身影。
