# LoRA



<!-- 正文开始 -->
**解释：** LoRA 是一种高效微调大模型的技术。传统微调需要更新全部参数，计算代价极高；LoRA 的做法是冻结原模型参数，只训练两个小的低秩矩阵（理解为「补丁」），大幅降低微调成本。比如在 Stable Diffusion 中用 LoRA 训练一个动漫风格的画风，只需要几十张图和几小时，而非几千张图和几天。

**为什么重要：** LoRA 让开源大模型的民主化成为可能——每个人都可以用自己的数据训练专属补丁，而无需重新训练整个模型。2023-2026 年几乎所有开源模型微调都用 LoRA 或其变种（QLoRA、DoRA）。
