# ReAct



<!-- 正文开始 -->
**解释：** ReAct 是 2023 年提出的让大模型能够同时推理和行动的方法论。核心思想是：在每次执行动作前，模型先输出一个「思考」（Thought）来推理当前情况，然后执行动作（Action），最后观察结果（Observation），形成「思考-行动-观察」的循环。ReAct = Reasoning + Acting。

**为什么重要：** ReAct 是 Agent 架构中最经典的行为模式之一，是 LangChain、AutoGen 等框架的底层 Agent Loop 设计基础。
