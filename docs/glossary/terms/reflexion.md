# Reflexion



<!-- 正文开始 -->
**解释：** Reflexion 是一种让 Agent 在失败后能够「反思并自我改进」的框架。当 Agent 执行某个任务失败时，它会分析失败原因，将反思结果存入长期记忆，下一次遇到类似任务时就能避免重复犯错。Reflexion 不更新模型权重，而是通过语言反馈让模型从错误中学习。

**为什么重要：** Reflexion 将 Agent 从「一次失败就结束」提升到「失败后学习再试」，是 AI Agent 具备持续自我改进能力的重要里程碑。
