# System Prompt



<!-- 正文开始 -->
**解释：** System Prompt 是给大模型的「角色设定」和「行为规则」，位于用户对话之上，告诉模型它是谁、该怎么回答、用什么风格。比如「你是一个专业的数据分析师，回答时用表格呈现数据」——这条规则就是 System Prompt，它对每次对话都生效，不像普通提示词只在单次问答中有效。

**为什么重要：** System Prompt 是定制 AI 行为最基础的手段，也是 AI 应用开发、Agent 架构中最重要的配置项之一。
