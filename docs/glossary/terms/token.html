术语

词元

英文：Token

解释： Token 是 LLM（大语言模型）处理文本的最小单元。中英文处理方式不同：英文用"词片段"（subword）切分，一个单词可能变成 2-3 个 token；中文以单字或词为 token，一个汉字 ≈ 1 个 token。

LLM 的费用是按消耗的 token 量计费的，所以 token 数量直接影响成本。

2025 年 1 月，国家语言文字工作委员会专家组将 "Token" 的中文定名确定为 "词元"，这是官方正式命名。

为什么重要： 理解 token 是理解 LLM 成本、能力和限制的基础。GPT-4 128K 上下文窗口约等于 96K 个英文单词或 64K 个中文字。
