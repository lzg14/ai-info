# Transformer



<!-- 正文开始 -->
**解释：** Transformer 是 2017 年谷歌在论文《Attention Is All You Need》中提出的深度学习架构。它完全抛弃了之前主流的 RNN（循环神经网络），仅用"注意力机制"（Attention Mechanism）来处理序列数据。

在此之前，处理长文本是 RNN 的噩梦——距离越远的词越难关联。Transformer 通过"自注意力"让任意两个词之间的关系都可以被直接建模，彻底改变了 NLP（自然语言处理）领域。

**为什么重要：** Transformer 是 GPT、BERT、ChatGPT 等所有现代大语言模型的基础架构。可以说，没有 Transformer，就没有今天的大模型。
