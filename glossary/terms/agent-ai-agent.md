### Agent

**英文：** Agent / AI Agent

**解释：**

AI Agent（智能体）是能够自主规划、分解任务、调用工具、并且在环境中执行操作的 AI 系统。与普通 ChatGPT 对话不同，Agent 能把复杂目标（如"帮我分析这家公司并写一份报告"）分解成多步骤，在每一步中自主决定使用什么工具、是否需要修正方向。

一个 Agent 通常包含：规划能力、工具调用（Function Calling）、记忆（短期+长期）和持续执行循环。

**为什么重要：** Agent 是 2025-2026 年 AI 应用落地最重要的方向，被视为通向 AGI（通用人工智能）的必经阶段。
